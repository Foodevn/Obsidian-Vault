# Ghi chú học tập: Tổng quan về OpenAI API và Quản lý Token

## OpenAI API

### Giới thiệu
- **OpenAI API**: Giao diện lập trình ứng dụng của OpenAI, cho phép tích hợp các mô hình [[LLM]] như [[ChatGPT]], [[GPT-4]], [[GPT-4o Mini]] vào các ứng dụng, tự động hóa hoặc [[AI Agents]].
- **Mục đích**: Tạo và quản lý **API keys**, thiết lập dự án, hiểu chi phí token, và tích hợp vào các công cụ như [[n8n]].

### Cách truy cập
- **Bước 1**: Truy cập [[OpenAI Playground]] qua [platform.openai.com](https://platform.openai.com/).
- **Bước 2**: Đăng nhập hoặc đăng ký tài khoản.
- **Giao diện**:
  - Tương tự [[ChatGPT]], cho phép thử nghiệm các mô hình như [[GPT-3.5]], [[GPT-4o Mini]].
  - Các tùy chọn:
    - **Model**: Chọn mô hình (ví dụ: GPT-4o Mini, GPT-4).
    - **Temperature**: Điều chỉnh độ sáng tạo (thấp = chính xác, cao = sáng tạo hơn).
    - **Max Tokens**: Giới hạn số token đầu ra (ví dụ: 16,000 token cho GPT-4o Mini).
    - **System Message**: Xác định vai trò của mô hình (ví dụ: "You are a helpful assistant"), quan trọng khi xây dựng AI agents.
    - **Stop Sequence**, **Top P**: Tùy chỉnh nâng cao (không cần thiết cho người mới bắt đầu).

### Thiết lập tài khoản và thanh toán
- **Thêm phương thức thanh toán**:
  - Vào **Profile** → **Billing** → **Payment Methods**.
  - Thêm thông tin thẻ tín dụng.
  - OpenAI áp dụng mô hình thanh toán theo sử dụng (pay-as-you-go).
- **Chi phí tối thiểu**:
  - Chỉ cần nạp $5 để bắt đầu (có thể đủ cho toàn khóa học).
  - OpenAI đôi khi cung cấp $5 tín dụng miễn phí cho người dùng mới.
- **Lưu ý**:
  - Có thể sử dụng [[Open-source LLMs]] (như [[LLaMA]]) để tránh chi phí, nhưng [[OpenAI API]] đáng tin cậy và dễ dùng.

### Chi phí token
- **Token**: Đơn vị tính toán trong LLM, khoảng 4 ký tự tiếng Anh = 1 token (1,500 từ ~ 2,048 token).
- **Giá token (theo OpenAI Pricing, tháng 8/2025)**:
  - **GPT-4o Mini** (khuyến nghị cho người mới):
    - Input: $0.15/1 triệu token (~750,000 từ).
    - Output: $0.60/1 triệu token.
  - **GPT-4o**:
    - Input: $2.50/1 triệu token.
    - Output: $10.00/1 triệu token.
  - **o1, o3 Mini**:
    - Input: $1.10/1 triệu token.
    - Output: $4.40/1 triệu token.
    - Hỗ trợ **function calling** và xuất dữ liệu có cấu trúc, phù hợp cho lập trình và toán học.
  - **o1**: Quá đắt, không khuyến nghị cho khóa học.
- **Ước tính chi phí**:
  - Với GPT-4o Mini, $1 đủ để thử nghiệm nhiều quy trình trong khóa học.
  - Sử dụng ít token khi thử nghiệm để tiết kiệm chi phí.

### Tạo và quản lý API Keys
- **Bước tạo API Key**:
  - Vào **Dashboard** → **API Keys** → **Create New Secret Key**.
  - Đặt tên (ví dụ: "n8n Course").
  - Chọn quyền (Permissions): 
    - **All**: Toàn quyền truy cập mọi mô hình (khuyến nghị).
    - **Restricted**: Giới hạn mô hình hoặc chỉ Old chỉ đọc (read-only).
  - Lưu ý: Sao chép và lưu API key ngay sau khi tạo (không thể xem lại sau khi đóng).
- **Bảo mật API Key**:
  - Không chia sẻ API key công khai để tránh bị lạm dụng (gây tính phí ngoài ý muốn).
  - **Xoay vòng key (Rotate Key)**:
    - Xóa key cũ (Revoke Key) và tạo key mới định kỳ để tăng bảo mật.
- **Tích hợp API Key**:
  - Sao chép API key và dán vào các công cụ như [[n8n]] để kết nối với OpenAI.

### Quản lý dự án
- **Dự án (Projects)**:
  - Mặc định: Tài khoản mới có một **Default Project**.
  - Tạo dự án mới: **Create Project** → Đặt tên (ví dụ: "n8n Course") → Gán API key cho dự án.
  - Có thể chia sẻ dự án với thành viên khác.
- **Thiết lập hạn mức (Limits)**:
  - Vào **Settings** → **Billing** → Đặt ngân sách (ví dụ: $10 để nhận cảnh báo qua email, $40 là giới hạn chi tiêu hàng tháng).
  - Theo dõi chi tiêu hàng ngày qua **Usage** (ví dụ: $0.38 ngày 19/2, $1.64 ngày 3/3).
- **Dành cho người dùng ở châu Âu**:
  - Chọn **Europe** làm khu vực khi tạo dự án mới để tuân thủ quy định bảo vệ dữ liệu [[GDPR]].
  - OpenAI cung cấp chính sách **zero data retention** cho dự án tại châu Âu, đảm bảo dữ liệu không được gửi ra ngoài khu vực.

### Các mô hình khác trong OpenAI API
- **Audio Models**: Hỗ trợ xử lý âm thanh, nhưng đắt hơn và không được sử dụng trong khóa học.
- **DALL-E, Whisper**: Mô hình tạo hình ảnh và chuyển giọng nói thành văn bản, không tập trung trong khóa học.
- **Reasoning Models (o1, o3 Mini)**:
  - Sử dụng **test-time compute** (tính toán tại thời điểm chạy), hiệu quả cho các tác vụ phức tạp nhưng đắt hơn.
  - Sẽ được giải thích chi tiết trong video tiếp theo.
