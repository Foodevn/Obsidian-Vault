## Các cách viết [[Vòng lặp]] (Loops) trong [[JavaScript]]

### 1. Sự đa dạng của Cú pháp (Syntax)

Trong JavaScript (cũng như nhiều ngôn ngữ lập trình khác), có rất nhiều cách khác nhau để thực thi một [[vòng lặp]] (loop). Dù sử dụng cách nào, mục tiêu cuối cùng vẫn là duyệt qua các phần tử của một `[[cấu trúc dữ liệu]]`. Việc chọn lựa cách viết chủ yếu ảnh hưởng đến **tính dễ đọc** của đoạn mã.

Dưới đây là các phiên bản khác nhau của hàm `findNemo` để minh họa cho sự đa dạng này:

### 2. Cách 1: Vòng lặp `for` truyền thống

_(Đã tìm hiểu ở các phần trước)_
Đòi hỏi khai báo biến đếm, điều kiện dừng và bước nhảy. Dù linh hoạt nhưng cú pháp khá dài dòng.

### 3. Cách 2: Sử dụng phương thức `forEach`

`forEach` là một phương thức tích hợp sẵn của mảng trong JavaScript, giúp duyệt qua từng phần tử mà không cần quan tâm đến chỉ số (index).

```JavaScript
function findNemo2(array) {
    // Duyệt qua từng 'fish' (item) trong mảng
    array.forEach(function(fish) {
        if (fish === 'nemo') {
            console.log('Found Nemo');
        }
    });
}
```

### 4. Cách 3: Sử dụng vòng lặp `for...of`

Đây là cú pháp hiện đại và thường được đánh giá là gọn gàng, gần gũi với ngôn ngữ tự nhiên nhất khi chỉ cần duyệt qua các giá trị của một tập hợp (collection).

```JavaScript
function findNemo3(array) {
    // Lặp qua mỗi 'fish' thuộc 'array'
    for (let fish of array) {
        if (fish === 'nemo') {
            console.log('Found Nemo');
        }
    }
}
```

### 5. Bài học rút ra: Sự cân bằng của Mã nguồn tốt (Good Code)

Nhắc lại hai trụ cột của mã nguồn tốt:
- **[[Tính khả mở (Scalability)]]**: Thể hiện qua `[[Big O Notation]]` (cách mã xử lý dữ liệu lớn). Tất cả các cách viết vòng lặp trên đều có cùng một Độ phức tạp thời gian là `[[O(n)]]`.
- **[[Tính dễ đọc (Readability)]]**: Thể hiện qua cú pháp. Tùy thuộc vào tình huống cụ thể và quy chuẩn của đội ngũ phát triển (team), bạn có thể chọn `forEach` hoặc `for...of` để giúp mã nguồn dễ hiểu và dễ bảo trì (maintainable) hơn so với vòng lặp `for` truyền thống.
