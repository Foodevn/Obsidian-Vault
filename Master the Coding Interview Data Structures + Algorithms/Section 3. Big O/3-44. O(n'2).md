## Mở rộng [[Quy tắc 3]] & Ký hiệu [[O(n^2)]] (Vòng lặp lồng nhau)

### Phân tích bài toán: In ra tất cả các cặp phần tử

Một dạng câu hỏi phỏng vấn rất phổ biến là yêu cầu bạn "in ra tất cả các cặp phần tử" (log all pairs) của một mảng. Ví dụ: với mảng `['a', 'b', 'c', 'd', 'e']`, bạn phải in ra `aa, ab, ac, ..., ea, eb...`.

Để giải quyết bài toán này, chúng ta thường sử dụng **vòng lặp lồng nhau** (nested loops):

```JavaScript
const boxes = ['a', 'b', 'c', 'd', 'e'];

function logAllPairsOfArray(array) {
  // Vòng lặp bên ngoài
  for (let i = 0; i < array.length; i++) {
    // Vòng lặp bên trong
    for (let j = 0; j < array.length; j++) {
      console.log(array[i], array[j]);
    }
  }
}

logAllPairsOfArray(boxes);
```

### Ký hiệu [[O(n^2)]] - Thời gian bậc hai

- Nếu 2 vòng lặp chạy **nối tiếp nhau** (cùng cấp thụt lề), chúng ta dùng phép **cộng**: $O(n) + O(n) = O(2n) \rightarrow O(n)$.
- Nhưng khi vòng lặp này nằm **bên trong** vòng lặp kia, với mỗi phần tử của vòng lặp ngoài, toàn bộ vòng lặp trong phải chạy lại từ đầu. Do đó, chúng ta dùng phép **nhân**: $O(n) * O(n) = O(n^2)$.
- **Tên gọi:** **[[Thời gian bậc hai]]** (Quadratic Time).
- **Tính chất:** Số lượng phép toán tăng lên theo cấp số nhân (bình phương) so với số lượng phần tử đầu vào.
    - Nếu có 2 phần tử $\rightarrow$ $2^2 = 4$ phép toán.
    - Nếu có 3 phần tử $\rightarrow$ $3^2 = 9$ phép toán.
- **Đánh giá hiệu suất:** Trên biểu đồ [[Big O]], $O(n^2)$ nằm ở vùng màu đỏ biểu thị mức độ **Rất tệ (Horrible)**. Đường biểu diễn của nó bị uốn cong và dốc đứng lên rất nhanh, khiến hệ thống chậm đi đáng kể khi dữ liệu lớn lên.

> **💡 Mẹo phỏng vấn:** Rất nhiều câu hỏi phỏng vấn bắt đầu bằng việc yêu cầu bạn đưa ra một giải pháp "ngây thơ" (thường có độ phức tạp là $O(n^2)$), sau đó thử thách bạn tối ưu hóa nó xuống các mức tốt hơn như $O(n)$ hoặc $O(n \log n)$.

### Kết hợp Quy tắc 3 với vòng lặp lồng nhau

Nhớ lại **Quy tắc 3: Các biến số khác nhau cho các đầu vào khác nhau**. Điều gì xảy ra nếu vòng lặp lồng nhau duyệt qua hai mảng hoàn toàn riêng biệt?

```JavaScript
function logPairsFromTwoArrays(arrayA, arrayB) {
  for (let i = 0; i < arrayA.length; i++) {        // O(a)
    for (let j = 0; j < arrayB.length; j++) {      // O(b)
      console.log(arrayA[i], arrayB[j]);
    }
  }
}
```

Lúc này, độ phức tạp **không phải** là $O(n^2)$ mà chính xác phải là **$O(a * b)$**.

### 📌 Mẹo ghi nhớ cốt lõi (Rule of Thumb)

- Các bước thực thi cùng cấp thụt lề (chạy nối tiếp) $\rightarrow$ **Cộng (+)**.
- Các bước thực thi khác cấp thụt lề (lồng nhau) $\rightarrow$ **Nhân (*)**.
