## Bài tập thực hành: Tính toán [[Big O]] từng dòng lệnh

### Mục đích của bài tập

- Bài tập này cố tình được thiết kế chi tiết (thậm chí có phần rắc rối) để minh họa cho bạn cách tư duy về từng bước thực thi của một hàm.
- **Lưu ý thực tế:** Trong các buổi phỏng vấn kỹ thuật, bạn sẽ **không** bị yêu cầu phải đếm chi tiết từng phép toán (operations) một cách thủ công như thế này. Mục đích ở đây là xây dựng nền tảng tư duy vững chắc trước khi học cách đơn giản hóa chúng.

### Phân tích hàm `funChallenge`

Dựa trên transcript, chúng ta có thể hình dung cấu trúc của hàm `funChallenge` và phân tích số lượng phép toán cho từng dòng lệnh như sau:

```JavaScript
function funChallenge(input) {
  let a = 10; // Khởi tạo biến -> Chạy 1 lần -> O(1)
  a = 50 + 3; // Gán lại giá trị -> Chạy 1 lần -> O(1)

  // Vòng lặp phụ thuộc vào kích thước của input (n)
  for (let i = 0; i < input.length; i++) { // O(n)
    anotherFunction();     // Gọi hàm bên ngoài -> Chạy n lần -> O(n)
    let stranger = true;   // Khởi tạo biến -> Chạy n lần -> O(n)
    a++;                   // Tăng giá trị (a = a + 1) -> Chạy n lần -> O(n)
  }
  
  return a; // Trả về kết quả -> Chạy 1 lần -> O(1)
}
```

### Cách tính toán tổng độ phức tạp

Nếu chúng ta cộng gộp tất cả các bước (operations) lại với nhau:

- Các lệnh chỉ chạy 1 lần: Khai báo `a`, gán lại `a`, và `return a` $\rightarrow$ $1 + 1 + 1 = 3$ bước.
- Các lệnh chạy lặp lại theo kích thước đầu vào (gọi tắt là $n$): Vòng lặp `for`, gọi `anotherFunction()`, khai báo `stranger`, và `a++` $\rightarrow$ $n + n + n + n = 4n$ bước.

**Kết quả thô (Raw Calculation):** Tổng số bước thực thi của hàm này là `BIG O(3 + 4n)`.

### Tóm lược & Bước tiếp theo

- Bài tập này chứng minh rằng việc tính toán [[Thời gian chạy]] (runtime) thực chất là đếm số lượng phép gán, phép tính và vòng lặp trong mã nguồn.
- **Bật mí:** Mặc dù kết quả chi tiết là `O(3 + 4n)`, nhưng trong thực tế tính toán Big O, kết quả này cuối cùng sẽ được **rút gọn chỉ còn [[O(n)]]**.
