## Bài tập thực hành 2: Tính toán chi tiết [[Big O]]

### Phân tích bài toán `anotherFunChallenge`

Dựa trên hướng dẫn của giảng viên, chúng ta tiếp tục thực hành đếm số lượng phép toán (operations) trên một hàm mới. Mặc dù mã nguồn chi tiết không được hiển thị đầy đủ, chúng ta có thể tái hiện lại cấu trúc logic của hàm này dựa trên kết quả tính toán:

```JavaScript
function anotherFunChallenge(input) {
  // Các phép gán biến ban đầu (chỉ chạy 1 lần)
  let a = 5;  // O(1)
  let b = 10; // O(1)
  let c = 50; // O(1)

  // Vòng lặp thứ nhất phụ thuộc vào đầu vào (input)
  for (let i = 0; i < input; i++) {
    let x = i + 1; // O(n)
    let y = i + 2; // O(n)
    let z = i + 3; // O(n)
  }

  // Vòng lặp thứ hai phụ thuộc vào đầu vào (input)
  for (let j = 0; j < input; j++) {
    let p = j * 2; // O(n)
    let q = j * 2; // O(n)
  }

  // Phép gán cuối cùng (chỉ chạy 1 lần)
  let whoAmI = "I don't know"; // O(1)
}
```

### Cách tổng hợp và tính toán

Thay vì tính nhẩm từng dòng một cách mệt mỏi, chúng ta có thể nhóm các phép toán lại:

- **Nhóm 1 - [[Thời gian hằng số]] (Constant Time):** Có tổng cộng 4 phép gán biến (variable assignments) nằm ngoài vòng lặp. Chúng chỉ chạy đúng một lần duy nhất bất kể kích thước của `input` là bao nhiêu $\rightarrow$ **4 bước (4 * O(1))**.
- **Nhóm 2 - [[Thời gian tuyến tính]] (Linear Time):** Bên trong các vòng lặp, có tổng cộng 5 thao tác tính toán/gán biến. Các thao tác này sẽ chạy lặp lại $n$ lần (với $n$ là kích thước của `input`) $\rightarrow$ **5n bước (5 * O(n))**.

**Kết quả thô (Raw Calculation):**
Cộng hai nhóm này lại, chúng ta có độ phức tạp Big O của toàn bộ hàm là: **O(4 + 5n)**.

### Bài học rút ra

- Việc đếm chi tiết từng bước (mathematical step-by-step count) giúp bạn hiểu sâu sắc bản chất về cách máy tính thực thi mã nguồn.
- Qua hai bài tập thực hành, bạn đã quen dần với việc phân biệt đâu là thao tác chạy 1 lần `O(1)` và đâu là thao tác chạy theo vòng lặp `O(n)`.
- Tuy nhiên, trong thực tế công việc và phỏng vấn, chúng ta sẽ không ngồi đếm chi tiết từng hằng số như thế này.
