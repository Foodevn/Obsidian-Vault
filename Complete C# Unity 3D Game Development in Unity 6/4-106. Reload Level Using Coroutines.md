## Tái Tải Scene Với Coroutine Khi Player Crashes

## 1. Tạo `GameSceneManager` Script

1. Scripts → Create C# Script → tên `GameSceneManager`
    
2. Empty GameObject `GameSceneManager` trong Hierarchy → add component `GameSceneManager`
    

csharp

`using UnityEngine; using UnityEngine.SceneManagement; public class GameSceneManager : MonoBehaviour {     // Public wrapper để gọi từ class khác     public void ReloadLevel()     {         StartCoroutine(ReloadLevelRoutine());     }     // Coroutine cho phép chờ trước khi reload     IEnumerator ReloadLevelRoutine()     {         yield return new WaitForSeconds(1f);      // chờ 1 giây         int currentSceneIndex = SceneManager.GetActiveScene().buildIndex;         SceneManager.LoadScene(currentSceneIndex);     } }`

## 2. Gọi `ReloadLevel()` Từ `CollisionHandler`

1. Mở `CollisionHandler.cs`
    
2. Thêm reference tới `GameSceneManager`:
    

csharp

`public class CollisionHandler : MonoBehaviour {     GameSceneManager sceneManager;     void Start()     {         // Tìm GameSceneManager trong Scene         sceneManager = FindFirstObjectByType<GameSceneManager>();     }     void OnTriggerEnter(Collider other)     {         if (other.CompareTag("Terrain") || /* điều kiện crash */)         {             sceneManager.ReloadLevel();  // gọi coroutine để reload có delay         }     } }`

## 3. Đảm Bảo Tag/Collider Đúng

- Player Ship có **Box Collider** và **Rigidbody** (IsTrigger = true)
    
- Terrain gán tag "Terrain" và có collider (IsTrigger = false)
    

## 4. Kiểm Thử

- Chạy Play Mode
    
- Player va chạm vào Terrain → chờ 1 giây → reload lại Scene hiện tại
    

---

**Lưu ý**:

- `IEnumerator` cho phép dùng `yield return new WaitForSeconds()` để delay
    
- `StartCoroutine(...)` khởi chạy Coroutine từ method đảo bảo kiểu trả về `void`
    
- Tách riêng `ReloadLevel()` (wrapper) và `ReloadLevelRoutine()` (coroutine) giúp tuân Single Responsibility Principle
