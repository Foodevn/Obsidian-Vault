## Tạo Nhiều Enemy Ship Bằng Prefab Variant

## 1. Tổ chức thư mục Prefabs

- Trong `Assets/Prefabs`, tạo các thư mục con:
    
    - **Player**: chứa `PlayerRig`, `PlayerLaser`, `PlayerDestroyedVFX`
        
    - **Enemy**: chứa `BaseEnemy`, `EnemyDestroyedVFX`
        
    - **VFX**: chứa tất cả hiệu ứng nổ và VFX chung
        

## 2. Tạo Base Enemy Prefab

1. Chọn GameObject **Enemy** trong Scene
    
2. Right-click → **Prefab → Create** → đặt tên `BaseEnemy`
    
3. Double-click `BaseEnemy` để vào Prefab Context
    
4. Trong `ModelEmpty`: xóa Model gốc, tạo Cube làm placeholder
    
5. Chuẩn hóa scale: tất cả transform là (1,1,1)
    

## 3. Tạo Variant cho Enemy

- **EnemyDestroyedVFX**
    
    1. Right-click `BaseDestroyedVFX` → **Create Prefab Variant** → tên `EnemyDestroyedVFX`
        
    2. Chỉnh module Particle tùy ý (màu cam, speed = 10) → **Overrides → Apply All**
        
- **Enemy Ship Variants**
    
    1. Right-click `BaseEnemy` → **Create Prefab Variant** → tên `EnemyShip1`
        
    2. Double-click `EnemyShip1` → trong `ModelEmpty`, xóa Cube, kéo model “RedFighter” vào
        
    3. Tinh chỉnh vị trí, rotation, thêm Box Collider + component `Enemy`
        
    4. Kéo Prefab `EnemyDestroyedVFX` vào field `Destroyed VFX` của component `Enemy`
        
    5. Lặp lại để tạo `EnemyShip2`, `EnemyShip3`, … với các model khác (WhiteFighter, YellowFighter…)
        

## 4. Thiết lập Box Collider & Component Enemy

- Trên Root GameObject của mỗi **EnemyShipX** (Prefab Variant):
    
    text
    
    `Component → Physics → Box Collider`
    
    - Điều chỉnh **Size** và **Center** để bao quanh model (cho phép dung sai hơi rộng)
        
    - Bỏ tick **Is Trigger**
        
- Thêm component `Enemy` (script xử lý va chạm với laser)
    
- Gán Prefab `EnemyDestroyedVFX` vào ô **Destroyed VFX**
    

## 5. Kiểm thử

1. Mở Scene mới **Ships**
    
2. Kéo vào ít nhất 3 prefab **EnemyShipX** và **PlayerRig**
    
3. Đưa PlayerRig và EnemyShips về vị trí (0,0,0) → kéo tách nhau để quan sát
    
4. Play Mode → bắn laser → enemy bị hủy và xuất hiệu ứng nổ cam
    

## 6. Ghi chú thêm

- **Prefab Variant** giúp tái sử dụng cấu hình gốc và tùy biến riêng cho từng variant
    
- Khi cần thay đổi chung (ví dụ scale, material), chỉnh trên `BaseEnemy` hoặc `BaseDestroyedVFX` → áp dụng xuống tất cả variants
    
- Dùng **Isometric View** (toggle góc nhìn) + `F` để focus object giúp canh collider chính xác
    
- Trong bài tiếp theo sẽ tinh chỉnh collider, camera và scale các ship cho phù hợp với gameplay
