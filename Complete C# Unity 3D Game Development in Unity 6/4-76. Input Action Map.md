## Tạo C# Script Đầu Tiên Để Xử Lý Unity Input Actions

## Giới thiệu về Input Actions Asset

- [[Unity]] cung cấp nhiều cách khác nhau để xử lý đầu vào (input), trong đó Input Actions Asset là một trong những phương pháp mạnh mẽ nhất
    
- Input Actions Asset cho phép tạo nhiều action maps (bản đồ hành động), mỗi cái phục vụ mục đích riêng như di chuyển người chơi, UI, minigame hay inventory
    
- Mỗi action map chứa nhiều actions (hành động) - ví dụ: move (di chuyển), look (nhìn), jump (nhảy), attack (tấn công)
    
- Ưu điểm lớn: có thể gán nhiều phím/nút khác nhau cho cùng một hành động, hỗ trợ đa nền tảng (PC, Nintendo Switch, Xbox) mà không cần viết lại code
    

## Tạo Player Controls Input Actions

- Trong thư mục Input, nhấp chuột phải → Create → Input Actions
    
- Đặt tên: `PlayerControls` (không có khoảng trắng)
    
- Double-click để mở và tạo action map mới bằng nút +
    
- Đặt tên action map: `Player`
    

## Thiết lập Action Move

- Tạo action đầu tiên với tên `Move`
    
- Loại action (Action Type): chọn Value thay vì Button vì cần trả về giá trị di chuyển
    
- Loại điều khiển (Control Type): chọn [[Vector2]] để nhận giá trị x và y (trái/phải, lên/xuống)
    
- Thêm binding bằng nút + → chọn Up/Down/Left/Right Composite
    
- Gán phím cho mỗi hướng:
    
    - Up: W key (nhấn Listen → nhấn W)
        
    - Down: S key
        
    - Left: A key
        
    - Right: D key
        
- Nhấn Save Asset để lưu
    

## Tạo Script Player Movement

- Tạo thư mục mới trong Assets: `Scripts`
    
- Trong thư mục Scripts: nhấp chuột phải → Create → [[C#]] Script
    
- Đặt tên: `PlayerMovement`
    

## Thiết lập cấu trúc GameObject

- Tạo Empty GameObject mới: `PlayerAirship`
    
- Đưa model của player vào làm con của PlayerAirship
    
- Đảm bảo PlayerAirship có position (0, 0, 0)
    
- Lý do: tách biệt logic di chuyển khỏi Player Rig (đang được điều khiển bởi [[Timeline]])
    

## Component Player Input

- Gắn component `Player Input` vào PlayerAirship
    
- Trong trường Actions: chọn `PlayerControls` (asset vừa tạo)
    
- Default Map sẽ tự động chọn `Player` vì chỉ có một action map
    
- Behavior: chọn `Send Messages` - phương pháp đơn giản nhất để tương tác với Input Actions
    
- Lưu ý quan trọng: Send Messages chỉ hoạt động với scripts gắn trên cùng GameObject với Player Input component
    
- Hệ thống tự động tạo function `OnMove()` tương ứng với action Move đã thiết lập
    

## Code xử lý Input

- Mở script PlayerMovement và thêm namespace:
    

csharp

`using UnityEngine.InputSystem;`

- Tạo method public OnMove để nhận dữ liệu từ Input System:
    

csharp

`public void OnMove(InputValue value) {     Debug.Log(value.Get<Vector2>()); }`

- Method này nhận tham số [[InputValue]] chứa dữ liệu từ action
    
- Sử dụng `value.Get<Vector2>()` để lấy giá trị vector2 từ input
    
- `Debug.Log()` để in ra Console và kiểm tra kết quả
    

## Kiểm tra kết quả

- Mở Console window
    
- Nhấn Play
    
- Test các phím:
    
    - A: trả về (-1, 0) - giá trị âm trên trục X
        
    - D: trả về (1, 0) - giá trị dương trên trục X
        
    - W: trả về (0, 1) - giá trị dương trên trục Y
        
    - S: trả về (0, -1) - giá trị âm trên trục Y
        

## Tối ưu Enter Play Mode

- Vào Edit → Project Settings → Editor
    
- Tìm phần Enter Play Mode
    
- Bỏ tích: Reload Domain và Reload Scene
    
- Lợi ích: tăng tốc độ compile khi vào Play mode
    
- Lưu ý: có thể gây vấn đề với [[static variables]] hoặc [[Scriptable Objects]], nhưng trong phạm vi bài học này không ảnh hưởng
    

## Ghi chú thêm

- Có nhiều cách khác để tương tác với Input Actions, Send Messages chỉ là một trong những cách đơn giản nhất
    
- Bài học tiếp theo sẽ sử dụng input để thực sự di chuyển tàu của người chơi
