## Thêm SFX và Music, và Giữ Music Chạy Liên Tục Qua Reload

## 1. Import Audio Assets

- Tải về từ Resources:
    
    - `MusicTrack.wav` (nhạc nền)
        
    - `ExplosionSFX.wav` (hiệu ứng nổ)
        
- Kéo thư mục `Music and SFX` vào `Assets/Imported Assets/Gdtv Assets`
    

---

## 2. Gắn SFX Cho Explosion VFX Prefab

1. `Assets/Prefabs/VFX/BaseDestroyedVFX.prefab`:
    
    - Add Component → **Audio Source**
        
    - Tham chiếu **Audio Clip** = `ExplosionSFX.wav`
        
    - Bật **Play On Awake** → nổ sẽ phát SFX ngay khi instantiated
        

---

## 3. Tạo Music Player với Loop và Volume

1. Hierarchy → Create Empty → đặt tên `MusicPlayer`
    
2. Add Component → **Audio Source**
    
    - **Audio Clip** = `MusicTrack.wav`
        
    - **Loop** = On
        
    - **Volume** = 0.11 (hoặc tuỳ chỉnh)
        

---

## 4. Giữ Music Không Restart Qua Reload (Singleton Pattern)

**MusicPlayer** → Add Component → `MusicPlayer.cs`:

csharp

`using UnityEngine; using UnityEngine.SceneManagement; public class MusicPlayer : MonoBehaviour {     void Awake()     {         int count = FindObjectsByType<MusicPlayer>(FindObjectsSortMode.None).Length;         if (count > 1)         {             Destroy(gameObject);           // Xóa bản mới nếu đã có MusicPlayer         }         else         {             DontDestroyOnLoad(gameObject); // Giữ lại qua reload         }     } }`

- Đảm bảo chỉ có 1 `MusicPlayer` tồn tại, không restart khi **SceneManager.LoadScene**
    

---

## 5. Kiểm Thử

- Play Mode → nghe nhạc nền loop liên tục
    
- Bắn nổ ship → nghe SFX explosion
    
- Chết và reload level → nhạc không dừng, SFX phát đúng
    

---

**Kết quả**:

- Explosion VFX có SFX đi kèm
    
- Nhạc nền loop liên tục, không restart khi reload scene
    
- Hiệu ứng âm thanh và nhạc nền hoàn thiện cho gameplay
