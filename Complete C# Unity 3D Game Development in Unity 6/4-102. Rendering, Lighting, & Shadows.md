## Tinh Chỉnh Hiển Thị, Ánh Sáng và Bóng Đổ

## 1. Tăng Khoảng Cách Bóng Đổ (Shadow Distance)

- **Edit → Project Settings → Quality → Rendering → Render Pipeline Asset**
    
- Chọn **Max Distance** của Shadows = 700 (bằng kích thước 1 block terrain)
    
- Đảm bảo camera vẫn nhận shadow ở khoảng cách xa
    

## 2. Giảm Độ Nhận Diện Bóng Đổ (Shadow Strength)

- Chọn **Directional Light** chính trong Hierarchy
    
- Inspector → Shadows → **Strength** ≈ 0.7
    
- Thêm **Directional Light** thứ hai làm fill light để làm mềm bóng
    
    - Màu sắc: tone lạnh hơn (hơi xanh)
        
    - Rotation khác light chính để chiếu sáng bổ sung
        

## 3. Bật Sương Mù (Fog)

- Window → Rendering → Lighting → **Environment**
    
- Bật **Fog**
    
    - Mode = Linear
        
    - Start Distance ≈ 100
        
    - End Distance ≈ 400
        
    - Color = xanh đêm (hơi tối)
        
- Game View → Toggle Fog hiển thị để xem kết quả
    

## 4. Cấu Hình Camera & Post-Processing

- Chọn **Main Camera (PlayerRig)**
    
    - Cài đặt **Post-Processing** = On
        
    - **Anti-Aliasing** (HDRP/URP): TAA (Temporal AA) cho mượt viền
        
    - **Quality → Rendering → Anti Aliasing** = Very High
        
    - **Contrast Adaptation** (nếu có) ≈ 0.8
        

## 5. Kiểm Thử & Điều Chỉnh

- Chạy Play Mode → quan sát: bóng cây kéo dài xa hơn, ánh sáng mềm mại, sương mù tạo chiều sâu
    
- Tinh chỉnh thêm:
    
    - Shadow Distance/Strength
        
    - Fog Start/End
        
    - Light Color (Temperature/Filter)
        
    - Anti-Aliasing method
