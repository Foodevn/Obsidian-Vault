## Xử Lý Va Chạm Giữa Laser và Enemy

## 1. Bật Collision Messages trên Particle System

- Chọn Prefab **Laser** (cả hai)
    
- Module **Collision** → Tích **Send Collision Messages**
    
- Nhấn **Overrides → Apply to Prefab** để áp dụng cho cả LeftLaser và RightLaser
    

## 2. Tạo Script Enemy

1. Trong thư mục **Scripts**, tạo C# Script tên `Enemy`
    
2. Gắn component `Enemy` vào Prefab hoặc GameObject mỗi enemy ship
    

## 3. Xử lý sự kiện OnParticleCollision

Mở `Enemy.cs` và thêm:

csharp

`using UnityEngine; public class Enemy : MonoBehaviour {     void OnParticleCollision(GameObject other)     {         // Hủy đối tượng enemy khi trúng laser         Destroy(this.gameObject);     } }`

- `OnParticleCollision(GameObject other)` gọi khi Particle System va chạm với collider không trigger
    
- `Destroy(this.gameObject)` xóa enemy khỏi scene
    

## 4. Kiểm thử

- Duplicate enemy test nhiều lần để kiểm tra đồng loạt
    
- Chạy Play Mode
    
- Bắn laser vào từng enemy → các enemy bị Destroy ngay khi trúng
