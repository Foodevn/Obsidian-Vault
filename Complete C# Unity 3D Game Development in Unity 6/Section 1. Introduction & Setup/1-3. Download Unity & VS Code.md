# Ghi chú học tập: Thiết lập môi trường phát triển với Unity 6 và Visual Studio Code

## Tổng quan
- **Mục tiêu**: Hướng dẫn cài đặt Unity Hub, Unity 6 và Visual Studio Code để bắt đầu phát triển game.
- **Nội dung**:
  - Tải và cài đặt Unity Hub để quản lý các phiên bản Unity và dự án.
  - Tải Unity 6 (phiên bản chính thức hoặc preview).
  - Tải và thiết lập Visual Studio Code làm trình soạn thảo mã (code editor).
  - Giải thích cơ bản về game engine và code editor.
- **Gợi ý liên kết**: [[Unity Hub]], [[Unity 6]], [[Visual Studio Code]]

## Nội dung chi tiết

### 1. Tải và cài đặt Unity Hub
- **Mô tả**:
  - Unity Hub là công cụ quản lý các phiên bản Unity và dự án game.
  - Tải từ trang chính thức: [unity.com/download](https://unity.com/download).
- **Hướng dẫn**:
  - Truy cập trang web, nhấn nút **Download** để tải trình cài đặt Unity Hub.
  - Thực hiện cài đặt theo các bước hướng dẫn (chọn "Yes" khi được yêu cầu).
  - Nếu được yêu cầu đăng nhập, tạo tài khoản Unity miễn phí với email.
- **Lưu ý**:
  - Đảm bảo cài đặt đúng thư mục mặc định hoặc theo ý muốn.
  - Unity Hub cung cấp giao diện với các tab: **Projects**, **Installs**, **Learn**, **Community**.
- **Gợi ý liên kết**: [[Unity Hub Installation]]

### 2. Cài đặt Unity 6
- **Mô tả**:
  - Unity 6 là phiên bản được sử dụng trong khóa học (chấp nhận phiên bản mới hơn).
  - Có các loại bản phát hành: **Official Releases**, **Pre-releases**, **Archive**.
  - **LTS (Long Term Support)**: Phiên bản ổn định, được hỗ trợ lâu dài.
- **Hướng dẫn**:
  - Trong Unity Hub, vào tab **Installs** → Nhấn **Install Editor** (góc trên bên phải).
  - Chọn **Unity 6 Preview** hoặc phiên bản LTS từ danh sách Official Releases.
  - Tùy chọn cài đặt thêm:
    - **WebGL Build Support**: Hỗ trợ xuất game lên website (khuyến nghị cài).
    - **Microsoft Visual Studio Community**: Không bắt buộc (khóa học dùng Visual Studio Code).
    - Các nền tảng khác (Android, iOS): Không cần thiết trong khóa học này.
  - Nhấn **Install** và chờ quá trình tải (thời gian phụ thuộc vào tốc độ internet).
- **Lưu ý**:
  - Có thể quay lại cài đặt thêm các thành phần (module) sau nếu cần.
- **Gợi ý liên kết**: [[Unity 6 Installation]], [[WebGL Build]]

### 3. Tải và cài đặt Visual Studio Code
- **Mô tả**:
  - Visual Studio Code (VS Code) là trình soạn thảo mã được chọn vì giao diện nhất quán trên Windows và Mac.
- **Hướng dẫn**:
  - Tải VS Code từ trang chính thức: [code.visualstudio.com](https://code.visualstudio.com).
  - Chọn phiên bản phù hợp với hệ điều hành (Windows, Mac, Linux).
  - Thực hiện cài đặt theo hướng dẫn (nhấn "Next" hoặc "Install" theo các bước).
- **Lưu ý**:
  - VS Code sẽ được thiết lập chi tiết trong các bài giảng sau.
  - Cài đặt trước và để sẵn sàng.
- **Gợi ý liên kết**: [[Visual Studio Code Setup]]

### 4. Tổng quan về Game Engine và Code Editor
- **Game Engine (Unity)**:
  - Là nền tảng phát triển game với giao diện trực quan.
  - Cung cấp các hệ thống có sẵn: vật lý (physics), đồ họa (rendering), âm thanh (audio).
  - So sánh với các game engine khác: Unreal, Godot, Game Maker.
- **Code Editor (Visual Studio Code)**:
  - Nơi viết mã nguồn (scripts) để điều khiển game engine.
  - Hỗ trợ gợi ý cú pháp, kiểm tra lỗi, và các tính năng lập trình nâng cao.
  - Lý do chọn VS Code: Giao diện thống nhất trên các hệ điều hành.
  - Các lựa chọn thay thế: Visual Studio Community, Rider, Notepad++.
- **Cách hoạt động**:
  - Mã nguồn được viết trong VS Code dưới dạng tệp **.cs** (C# scripts).
  - Tệp .cs chứa các lệnh điều khiển Unity (ví dụ: di chuyển đối tượng game đi 10 đơn vị).
  - Unity thực thi các lệnh từ scripts để điều khiển hành vi game.
- **Gợi ý liên kết**: [[Game Engine]], [[C# Scripts]], [[Unity Workflow]]
