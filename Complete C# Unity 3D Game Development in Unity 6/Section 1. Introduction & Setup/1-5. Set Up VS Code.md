# Ghi chú học tập: Thiết lập Visual Studio Code cho Unity

## Tổng quan
- **Mục tiêu**: 
  - Cấu hình Visual Studio Code (VS Code) làm trình soạn thảo mã (code editor) cho Unity.
  - Tạo và kiểm tra một script C# cơ bản để đảm bảo kết nối giữa Unity và VS Code.
  - Cài đặt các tiện ích mở rộng (extensions) cần thiết để hỗ trợ lập trình Unity.
  - Hiểu vai trò của các tiện ích mở rộng và cách xử lý sự cố.
- **Gợi ý liên kết**: [[Visual Studio Code]], [[C# Scripts]], [[Unity Extensions]]

## Nội dung chi tiết

### 1. Thiết lập VS Code trong Unity
- **Mô tả**: Cấu hình Unity để sử dụng VS Code làm trình soạn thảo mã mặc định.
- **Hướng dẫn**:
  - Trong Unity, vào **Edit** (hoặc **Unity** trên Mac) → **Preferences**.
  - Trong cửa sổ Preferences, chọn tab **External Tools**.
  - Tìm mục **External Script Editor**:
    - Nếu chưa chọn VS Code, nhấp vào menu thả xuống và chọn **Visual Studio Code**.
    - Nếu sử dụng trình soạn thảo khác (như Visual Studio Community, Rider), chọn tùy chọn tương ứng.
  - Đóng cửa sổ Preferences sau khi thiết lập.
- **Lưu ý**:
  - Thiết lập này đảm bảo các script C# trong Unity sẽ mở trực tiếp trong VS Code.
- **Gợi ý liên kết**: [[Unity Preferences]], [[External Script Editor]]

### 2. Tạo script C# trong Unity
- **Mô tả**: Tạo một script C# đơn giản để kiểm tra kết nối với VS Code.
- **Hướng dẫn**:
  - Trong tab **Project** → Nhấp chuột phải → **Create** → **C# Script**.
  - Đặt tên script (ví dụ: **TestDeleteMe**) trước khi nhấp ra ngoài.
  - Nhấn Enter để xác nhận tên.
  - Nhấp đúp vào script trong tab Project để mở trong VS Code.
- **Kết quả**:
  - VS Code mở script với nội dung mặc định (một class C# cơ bản).
  - Có thể xuất hiện thông báo "Do you trust the authors?" → Chọn **Yes** (vì script do bạn tạo).
- **Lưu ý**:
  - Script này chỉ để kiểm tra, sẽ được xóa sau khi hoàn thành.
  - Nếu VS Code không mở, kiểm tra lại thiết lập External Script Editor.
- **Gợi ý liên kết**: [[C# Script Creation]], [[Unity Assets]]

### 3. Cài đặt Extensions trong VS Code
- **Mô tả**: Cài đặt các tiện ích mở rộng để hỗ trợ lập trình Unity trong VS Code.
- **Hướng dẫn**:
  - Trong VS Code, vào tab **Extensions** (biểu tượng ô vuông ở thanh bên trái).
  - Tìm kiếm và cài đặt các tiện ích sau:
    - **Unity**: Tích hợp VS Code với Unity, hỗ trợ gợi ý mã và debug.
      - Tìm từ khóa "Unity" → Chọn extension đầu tiên → Nhấn **Install**.
    - **Unity Code Snippets** (bởi Kleber Silva): Cung cấp các đoạn mã mẫu (code snippets) cho Unity.
      - Tìm từ khóa "Unity Code Snippets" → Chọn và nhấn **Install**.
    - **C# Dev Kit** và **C# Extension** (khuyến nghị): Hỗ trợ lập trình C# (thường được cài tự động).
  - Kiểm tra trạng thái:
    - Nếu đã cài, nút sẽ hiển thị **Disable** hoặc **Uninstall**.
    - Nếu chưa cài, nhấn **Install** để cài đặt.
- **Lợi ích của Extensions**:
  - **Unity Extension**: Tăng cường tích hợp với Unity, hỗ trợ nhận diện các API của Unity.
  - **Unity Code Snippets**: Tự động gợi ý các hàm phổ biến như `Start()`, `Update()`, tiết kiệm thời gian.
  - **C# Extensions**: Hỗ trợ cú pháp C#, kiểm tra lỗi (hiển thị gạch đỏ dưới lỗi cú pháp), và gợi ý mã.
- **Ví dụ**:
  - Gõ `start` trong VS Code → Extension gợi ý hàm `Start()` → Nhấn Tab để tự động hoàn thành.
  - Gõ mã sai (như `Asdf`) → Xuất hiện gạch đỏ dưới mã, báo lỗi cú pháp.
- **Gợi ý liên kết**: [[VS Code Extensions]], [[C# Debugging]]

### 4. Xử lý sự cố với VS Code
- **Vấn đề tiềm năng**:
  - VS Code không mở script hoặc hoạt động không đúng.
  - Thiếu tích hợp với Unity (không nhận diện API Unity, không gợi ý mã).
- **Giải pháp**:
  - Kiểm tra lại thiết lập External Script Editor trong Unity Preferences.
  - Đảm bảo đã cài đặt các extensions cần thiết (Unity, Unity Code Snippets, C#).
  - Tham khảo tài liệu xử lý sự cố trong phần **Discussions** của bài giảng (liên kết được cung cấp trong khóa học).
  - Nếu cần, cài đặt lại VS Code hoặc các extensions.
- **Gợi ý liên kết**: [[VS Code Troubleshooting]], [[Unity-VS Code Integration]]

### 5. Sử dụng dự án "Zany Vehicle" để thử nghiệm
- **Mục đích**:
  - Dự án "Zany Vehicle" là không gian an toàn để thử nghiệm và làm quen với Unity/VS Code.
  - Có thể quay lại dự án này để thử các tính năng mới mà không ảnh hưởng đến các dự án chính.
- **Lời khuyên**:
  - Thử tạo thêm game objects, scripts, hoặc thay đổi giao diện để làm quen.
  - Không lo phá hỏng dự án vì đây chỉ là dự án thực hành.
- **Gợi ý liên kết**: [[Zany Vehicle Project]], [[Unity Sandbox]]
