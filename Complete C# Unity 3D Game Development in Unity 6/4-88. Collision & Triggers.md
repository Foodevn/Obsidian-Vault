## Xử Lý Va Chạm (Collisions & Triggers) Cho Player Ship

## 1. Thêm Collider và Rigidbody cho Player Ship

- Chọn **PlayerShip** trong Hierarchy
    
- **Component → Physics → Box Collider**
    
    - Kích thước (Size) ước lượng ~ (10,10,10)
        
    - Di chuyển Center lên cao để bao quanh phần thân tàu, không chạm đuôi
        
    - Bật **Is Trigger** để nhận sự kiện trigger, không gây va đập vật lý
        
- **Component → Physics → Rigidbody**
    
    - Bỏ chọn **Use Gravity** để chỉ nhận trigger, không rơi
        

## 2. Thêm đối tượng Test Enemy

- Import model tàu địch (ví dụ: “big red chunky boy”)
    
- Đặt ở gần điểm khởi đầu, dễ lái vào để test va chạm
    
- **Component → Physics → Box Collider**
    
    - Tinh chỉnh Size cho phù hợp
        
    - Giữ Is Trigger tắt để player trigger với enemy trigger
        

## 3. Nguyên tắc Trigger & Collision trong Unity

- **PlayerShip** có Rigidbody + Trigger Collider → sẽ nhận OnTriggerEnter khi chạm mọi collider khác
    
- Nếu cả 2 Collider đều tĩnh (không có Rigidbody) → không nhận sự kiện
    
- Quy tắc: ít nhất một bên phải có Rigidbody để tương tác trigger/collision
    

## 4. Tạo Script Xử Lý Va Chạm

1. Trong thư mục **Scripts**, tạo **C# Script** tên `CollisionHandler`
    
2. Gắn component `CollisionHandler` vào **PlayerShip**
    
3. Mở `CollisionHandler.cs` và thêm code:
    

csharp

`using UnityEngine; public class CollisionHandler : MonoBehaviour {     void OnTriggerEnter(Collider other)     {         // Cách 1: String concatenation         // Debug.Log("Hit " + other.gameObject.name);                  // Cách 2: String interpolation         Debug.Log($"Hit {other.gameObject.name}");     } }`

- `OnTriggerEnter(Collider other)` gọi khi PlayerShip chạm trigger collider khác
    
- Sử dụng `other.gameObject.name` để in tên object vào Console
    
- Có thể dùng string concatenation hoặc interpolation
    

## 5. Kiểm thử

- Chạy Play Mode
    
- Lái PlayerShip va chạm **EnemyShip** → in `Hit TestEnemy`
    
- Va chạm Terrain (có Terrain Collider) → in `Hit Terrain`
    
- Console xác nhận sự kiện trigger hoạt động đúng
    

## 6. Ghi chú thêm

- Cần tắt collider thử nghiệm (ví dụ sphere debug) để không ảnh hưởng sau này
    
- Sẽ thêm logic cho đối tượng địch và phản hồi khi bị bắn trong các bài sau
    
- Sử dụng mix string interpolation giúp code gọn và dễ đọc hơn
