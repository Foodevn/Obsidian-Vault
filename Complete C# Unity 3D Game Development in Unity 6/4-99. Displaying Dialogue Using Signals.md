## Thiết Lập Văn Bản Lời Thoại Với Signal trên Timeline

## Mục tiêu

- Hiển thị lời thoại (voice lines) dạng text ở đáy màn hình theo từng đoạn audio
    
- Dùng **Signal Emitter**, **Signal Receiver** và **Signal Asset** để đồng bộ text và audio
    

---

## 1. Tạo UI Text cho Lời Thoại

1. UI Canvas → **UI → Text - TextMeshPro** → đổi tên `DialogueText`
    
2. Rect Transform:
    
    - Anchor & Pivot = Bottom Stretch (Shift+Alt+click bottom-stretch preset)
        
    - Pos X = 0, Pos Y = 10
        
    - Width stretch full, Height đủ chứa 2 dòng text
        
3. TMP Settings:
    
    - Font Asset = Roboto (giống Scoreboard)
        
    - Font Size ≈ 48
        
    - Alignment = Center (both axes)
        
    - Chặn Wrap = No Wrap hoặc fix Width lớn
        

---

## 2. Tạo Script `DialogueLines`

csharp

`using UnityEngine; using TMPro; public class DialogueLines : MonoBehaviour {     [SerializeField] TMP_Text dialogueText;  // Reference tới DialogueText     [SerializeField] string[] lines;         // Mảng chứa từng đoạn thoại     int currentLine = 0;                     // Chỉ số dòng hiện tại     // Gọi khi nhận signal     public void NextDialogueLine()     {         dialogueText.text = lines[currentLine];         currentLine++;         if (currentLine >= lines.Length) currentLine = 0; // Loop nếu cần     } }`

- Kéo component `DialogueLines` vào empty GameObject `DialogueManager`
    
- Kéo `DialogueText` vào ô **Dialogue Text**
    
- Đặt **Lines Size** = 8, nhập 8 câu thoại theo thứ tự
    

---

## 3. Tạo Signal Asset

- Project → Folder `Timelines` → **Create → Signal Asset** → đặt tên `NextDialogueLine`
    

---

## 4. Thiết Lập Signal Receiver

- Chọn `DialogueManager` → Add Component → **Signal Receiver**
    
- Nhấn **+** tại **Signals**
    
    - GameObject = `DialogueManager`
        
    - Component = `DialogueLines`
        
    - Function = `NextDialogueLine()`
        

---

## 5. Gắn Signal Emitters trên Timeline

1. Mở **Master Timeline**
    
2. Tạo **Track → Signal Track** trong nhóm `VoiceLines`
    
3. Chọn Signal Track → Right-click → **Add Signal Emitter**
    
4. Chọn **Signal Asset** = `NextDialogueLine`
    
5. Chọn Signal Emitter clip → Inspector → **Signal Receiver** = `DialogueManager`
    
6. **Reaction** = `NextDialogueLine()`
    
7. Kéo Signal Emitters vào vị trí sát trước mỗi voice line audio
    

---

## 6. Kiểm Thử

- Chạy Play Mode → audio phát, text tại đáy màn hình tự động cập nhật theo từng signal marker
    

---

**Chú ý**:

- Signal Emitter (marker) dùng để kích hoạt sự kiện tại điểm chính xác trên Timeline
    
- Signal Receiver lắng nghe và gọi public method tương ứng
    
- Signal Asset kết nối emitter và receiver, cho phép tái sử dụng nhiều lần trên các Timeline khác nhau
