## Kết Nối Các Class Qua Public Methods

## 1. Tạo `Scoreboard` Script & GameObject

- Create → C# Script → tên `Scoreboard`
    
- Thêm một **Empty GameObject** trong Scene → đặt tên `Scoreboard` → gắn component `Scoreboard`
    

csharp

`using UnityEngine; public class Scoreboard : MonoBehaviour {     int score = 0;  // điểm hiện tại     // Phương thức tăng điểm, public để gọi từ class khác     public void IncreaseScore(int amount)     {         score += amount;               // score = score + amount         Debug.Log(score);              // in giá trị score ra Console     } }`

## 2. Sửa `Enemy` Class Gọi `IncreaseScore()`

- Mỗi biến thể Enemy (Prefab Variant) có trường `hitpoints` và `scoreValue` riêng
    
- Tham chiếu tới `Scoreboard` thông qua `FindFirstObjectByType<Scoreboard>()`
    

csharp

`using UnityEngine; public class Enemy : MonoBehaviour {     [SerializeField] int hitpoints = 4;        // HP của từng variant     [SerializeField] int scoreValue = 20;      // số điểm khi hủy     [SerializeField] GameObject destroyedVFX;     Scoreboard scoreboard;     void Start()     {         // Tìm reference tới Scoreboard trong Scene         scoreboard = FindFirstObjectByType<Scoreboard>();     }     void OnParticleCollision(GameObject other)     {         ProcessHit();     }     void ProcessHit()     {         hitpoints--;         if (hitpoints <= 0)         {             // Tạo VFX nổ             Instantiate(destroyedVFX, transform.position, Quaternion.identity);             // Tăng điểm lên Scoreboard             scoreboard.IncreaseScore(scoreValue);             Destroy(gameObject);         }     } }`

## 3. Thiết lập Prefab Variant & Giá trị Riêng

- Mỗi **EnemyShipX** kéo component `Enemy` vào, gán `hitpoints` và `scoreValue` phù hợp
    
- Ví dụ:
    
    - Beetle: `hitpoints = 10`, `scoreValue = 100`
        
    - Grasshopper: `hitpoints = 2`, `scoreValue = 5`
        
    - Wasp: `hitpoints = 4`, `scoreValue = 15`
        
    - Butterfly: `hitpoints = 6`, `scoreValue = 50`
        
    - Moth: `hitpoints = 4`, `scoreValue = 15`
        

## 4. Kiểm thử

- Chạy Play Mode → bắn laser trúng enemy nhiều lần
    
- Quan sát Console: value của score tăng theo `scoreValue` mỗi khi hủy enemy
    

## 5. Ghi chú về Giao tiếp Giữa Class

- Dùng **public method** (`IncreaseScore`) để cho phép class `Enemy` gọi từ `Scoreboard`
    
- Tham chiếu component dùng `FindFirstObjectByType<T>()` tránh serialized field không phù hợp cho prefab spawn runtime
    
- Tách trách nhiệm:
    
    - `Scoreboard` quản lý điểm
        
    - `Enemy` xử lý va chạm, HP và gọi tăng điểm
        
- Mở rộng: có thể tách Health logic ra class riêng (SRP – Single Responsibility Principle) để code dễ bảo trì hơn
