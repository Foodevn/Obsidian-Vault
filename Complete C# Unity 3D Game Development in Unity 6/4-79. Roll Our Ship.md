## Xoay Tàu Theo Hướng Di Chuyển (Roll Rotation)

## Khái niệm về Roll, Pitch và Yaw

Trong không gian 3D, có 3 kiểu xoay cơ bản:

- **Roll** (lăn): xoay quanh trục Z (màu xanh dương) - tàu nghiêng trái/phải
    
- **Pitch** (ngẩng): xoay quanh trục X (màu đỏ) - mũi tàu lên/xuống
    
- **Yaw** (quay): xoay quanh trục Y (màu xanh lá) - tàu quay trái/phải
    

## Quaternion và Euler Angles

**[[Quaternion]]**:

- Cách Unity mã hóa (encode) rotations bên trong
    
- Rất phức tạp ở mức sâu, nhưng không cần hiểu hết
    
- Chỉ cần biết: đó là cách biểu diễn góc xoay
    

**[[Euler Angles]]** (đọc là "Oy-ler", không phải "Ju-ler"):

- Cách dễ hiểu hơn để làm việc với rotation
    
- Dịch quaternion thành giá trị X, Y, Z mà con người dễ hiểu
    
- Roll → Z axis
    
- Pitch → X axis
    
- Yaw → Y axis
    

## Lưu ý quan trọng về thứ tự xoay

**Thứ tự xoay ảnh hưởng đến kết quả:**

Ví dụ trong Inspector của PlayerAirship:

- Nếu pitch trước → rồi roll sau: chỉ ảnh hưởng đúng các trục
    
- Nếu roll trước → rồi pitch sau: cả 3 giá trị X, Y, Z đều thay đổi
    

→ Điều này quan trọng khi viết code xử lý rotation

Nhớ reset về (0, 0, 0) bằng Ctrl + Z trước khi tiếp tục

## Tạo method ProcessRotation

Trong Update(), thêm:

csharp

`void Update() {     ProcessTranslation();     ProcessRotation(); } void ProcessRotation() {     // Code xử lý rotation }`

- Xóa từ khóa `private` vì C# tự hiểu method là private nếu không khai báo
    
- Giữ nhất quán với `ProcessTranslation()`
    

## Hard-code test rotation

Thử nghiệm snap tàu về góc 45 độ:

csharp

`void ProcessRotation() {     transform.localRotation = Quaternion.Euler(0f, 0f, 45f); }`

- `Quaternion.Euler(x, y, z)` chuyển Euler angles thành Quaternion
    
- Không cần xoay X (pitch) hay Y (yaw), chỉ cần Z (roll)
    
- Giá trị 45 trên trục Z
    

**Kết quả khi test:**

- Tàu snap ngay lập tức về góc 45 độ bên trái khi Play
    
- Không xoay liên tục, chỉ snap về vị trí cố định mỗi frame
    

**Ghi chú:**

- 45 độ = nghiêng trái (positive Z)
    
- -45 độ = nghiêng phải (negative Z)
    
- 45 độ hơi quá nhiều, cần giảm xuống
    

## Tạo biến Control Roll Factor

Ở đầu class, thêm serialized field:

csharp

`// Movement variables [SerializeField] float controlSpeed = 50f; [SerializeField] float xClampRange = 35f; [SerializeField] float yClampRange = 20f; // Rotation variables [SerializeField] float controlRollFactor = 20f;`

- Để trống một dòng giữa movement và rotation cho dễ đọc
    
- Giá trị 20f thay vì 45f để rotation nhẹ nhàng hơn
    
- Lưu ý: "control" chỉ có một chữ "l"
    

## Áp dụng Roll theo hướng di chuyển

Cập nhật ProcessRotation():

csharp

`void ProcessRotation() {     Quaternion targetRotation = Quaternion.Euler(         0f,          0f,          -controlRollFactor * movement.x     );          transform.localRotation = targetRotation; }`

**Giải thích:**

- `movement.x` trả về -1 (trái), +1 (phải), hoặc 0 (không nhấn)
    
- Nhân với `controlRollFactor` để có góc xoay mong muốn
    
- Dấu âm (`-`) để đảm bảo tàu nghiêng đúng hướng:
    
    - Di chuyển trái (movement.x = -1) → roll dương (nghiêng trái)
        
    - Di chuyển phải (movement.x = +1) → roll âm (nghiêng phải)
        

**Tại sao cần dấu âm:**

- Theo mental note khi test, +45 nghiêng trái, -45 nghiêng phải
    
- Có thể đặt dấu âm ở 3 vị trí: trước `controlRollFactor`, trước `movement.x`, hoặc trong giá trị khởi tạo
    
- Đặt trực tiếp trong code dễ hiểu nhất
    

## Ưu điểm của Input System

Khi không nhấn phím:

- `movement.x` tự động về 0
    
- Tàu tự động xoay về rotation.z = 0 trong Update()
    
- Không cần code thêm logic reset
    

## Vấn đề hiện tại

Tàu snap (nhảy) ngay lập tức giữa các góc xoay:

- Trông không mượt mà
    
- Cần sử dụng [[Linear Interpolation]] (Lerp) để xoay dần dần
    
- Sẽ xử lý trong lecture tiếp theo
    

## Code hoàn chỉnh hiện tại

csharp

`using UnityEngine; using UnityEngine.InputSystem; public class PlayerMovement : MonoBehaviour {     [SerializeField] float controlSpeed = 50f;     [SerializeField] float xClampRange = 35f;     [SerializeField] float yClampRange = 20f;          [SerializeField] float controlRollFactor = 20f;          Vector2 movement;          void Update()     {         ProcessTranslation();         ProcessRotation();     }          public void OnMove(InputValue value)     {         movement = value.Get<Vector2>();     }          void ProcessTranslation()     {         float xOffset = movement.x * controlSpeed * Time.deltaTime;         float yOffset = movement.y * controlSpeed * Time.deltaTime;                  float rawXPos = transform.localPosition.x + xOffset;         float clampedXPos = Mathf.Clamp(rawXPos, -xClampRange, xClampRange);                  float rawYPos = transform.localPosition.y + yOffset;         float clampedYPos = Mathf.Clamp(rawYPos, -yClampRange, yClampRange);                  transform.localPosition = new Vector3(             clampedXPos,             clampedYPos,             0f         );     }          void ProcessRotation()     {         Quaternion targetRotation = Quaternion.Euler(             0f,              0f,              -controlRollFactor * movement.x         );                  transform.localRotation = targetRotation;     } }`
