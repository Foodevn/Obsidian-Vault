## Giới Hạn Di Chuyển Của Tàu Bằng Clamping

## Vấn đề cần giải quyết

- Tàu có thể di chuyển ra ngoài màn hình không giới hạn
    
- Cần thiết lập ranh giới (boundary) để giữ tàu trong vùng chơi
    

## Sử dụng Mathf.Clamp()

Method `Mathf.Clamp()` nhận 3 tham số:

- Giá trị cần giới hạn (value)
    
- Giá trị tối thiểu (min)
    
- Giá trị tối đa (max)
    

Nếu giá trị nằm ngoài khoảng min-max, nó sẽ được "kẹp" (clamp) về điểm gần nhất

## Refactor code để dễ đọc

Thay vì code phức tạp:

csharp

`transform.localPosition = new Vector3(     transform.localPosition.x + xOffset,     // ... );`

Tách thành các bước rõ ràng hơn:

csharp

`float rawXPos = transform.localPosition.x + xOffset; float clampedXPos = Mathf.Clamp(rawXPos, -xClampRange, xClampRange);`

## Khai báo biến giới hạn trục X

Ở đầu class, thêm:

csharp

`[SerializeField] float xClampRange = 5f;`

- Giá trị khởi tạo 5f quá nhỏ (chỉ để demo)
    
- Sẽ điều chỉnh sau trong Inspector
    

## Triển khai Clamp cho trục X

Trong method `ProcessTranslation()`:

csharp

`private void ProcessTranslation() {     float xOffset = movement.x * controlSpeed * Time.deltaTime;     float yOffset = movement.y * controlSpeed * Time.deltaTime;          float rawXPos = transform.localPosition.x + xOffset;     float clampedXPos = Mathf.Clamp(rawXPos, -xClampRange, xClampRange);          transform.localPosition = new Vector3(         clampedXPos,         transform.localPosition.y + yOffset,         0f     ); }`

## Điều chỉnh giá trị X Clamp Range

- Chạy Play Mode và test
    
- Thử các giá trị:
    
    - 5: quá chật
        
    - 30: khá tốt
        
    - 35: rộng rãi, cho phép tàu tràn qua viền màn hình một chút
        
- Giá trị 35 tạo cảm giác tha thứ (forgiving) cho người chơi, tốt cho testing
    

## Challenge: Clamp trục Y

Tương tự trục X, thêm code cho trục Y:

csharp

`[SerializeField] float yClampRange = 20f;`

Trong `ProcessTranslation()`:

csharp

`private void ProcessTranslation() {     float xOffset = movement.x * controlSpeed * Time.deltaTime;     float yOffset = movement.y * controlSpeed * Time.deltaTime;          float rawXPos = transform.localPosition.x + xOffset;     float clampedXPos = Mathf.Clamp(rawXPos, -xClampRange, xClampRange);          float rawYPos = transform.localPosition.y + yOffset;     float clampedYPos = Mathf.Clamp(rawYPos, -yClampRange, yClampRange);          transform.localPosition = new Vector3(         clampedXPos,         clampedYPos,         0f     ); }`

## Điều chỉnh giá trị Y Clamp Range

- Aspect ratio (tỷ lệ khung hình) 16:9 khiến chiều dọc ngắn hơn chiều ngang
    
- Thử các giá trị:
    
    - 35: quá cao
        
    - 20: khá vừa
        
    - 25: có vẻ hơi cao
        
- Giá trị cuối: khoảng 20-25 tùy preference (sở thích)

## Lưu ý quan trọng về Position

Nếu clamping không hoạt động đúng, kiểm tra:

- PlayerRig
    
- PlayerAirship
    
- Model con
    

Đảm bảo tất cả đều có position (0, 0, 0) tương đối với GameObject cha, nếu không sẽ có di chuyển không mong muốn

## Lưu giá trị sau Play Mode

**Nhớ**: sau khi thoát Play Mode, phải set lại giá trị trong Inspector:

- X Clamp Range: 35
    
- Y Clamp Range: 20-25
