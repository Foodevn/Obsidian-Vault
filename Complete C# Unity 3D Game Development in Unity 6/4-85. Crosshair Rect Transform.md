## Thiết Lập UI Canvas Và Crosshair Theo Chuột

## 1. Import Crosshair Sprite

- Tải về file PNG **crosshair** trong Resources
    
- Kéo vào thư mục trong `Assets` (ví dụ `Gdtv Assets`)
    
- Chọn image → Inspector → đổi **Texture Type** thành _Sprite (2D and UI)_ → **Sprite Mode** = Single → Apply
    

## 2. Tạo Canvas và Image

1. Hierarchy → Right-click → UI → **Canvas** → đặt tên `UI Canvas`
    
2. Con của `UI Canvas` → Right-click → UI → **Image** → đặt tên `Crosshair`
    
3. Chọn `Crosshair` → Inspector → Image → kéo sprite crosshair vào mục **Source Image**
    

## 3. Thiết Lập Canvas Scaler

- Chọn `UI Canvas` → Inspector → **Canvas Scaler**
    
- **UI Scale Mode** = _Scale With Screen Size_
    
- **Reference Resolution** = 1920×1080 (tỷ lệ 16:9)
    
- Đảm bảo crosshair giữ kích thước và vị trí tương ứng trên mọi độ phân giải
    

## 4. Lập Trình Di Chuyển Crosshair Theo Chuột

- Mở script **PlayerWeapon.cs**
    
- Khai báo biến RectTransform:
    
    csharp
    
    `[SerializeField] RectTransform crosshair;`
    
- Thêm method gọi mỗi frame:
    
    csharp
    
    `void Update() {     MoveCrosshair();     ProcessFiring(); // giữ phần cũ } void MoveCrosshair() {     crosshair.position = Mouse.current.position.ReadValue(); }`
    
- Lưu script → Unity → kéo GameObject `Crosshair` vào ô `Crosshair` của component `PlayerWeapon`
    

## 5. Tắt Con Trỏ Chuột Mặc Định

- Trong `PlayerWeapon.cs`, thêm Start():
    
    csharp
    
    `void Start() {     Cursor.visible = false; }`
    
- Kết quả: con trỏ ẩn khi game window được focus

**Kết quả chung**:

- Crosshair luôn hiển thị phía trên (screen space overlay)
    
- Di chuyển mượt theo chuột trong game view
    
- Con trỏ hệ thống bị ẩn hoàn toàn khi bắt đầu chơi
