## Làm Mượt Rotation Bằng Lerp

## Khái niệm Lerp (Linear Interpolation)

**[[Lerp]]** là viết tắt của Linear Interpolation (nội suy tuyến tính):

- Di chuyển/thay đổi mượt mà từ điểm A sang điểm B
    
- Diễn ra trong một khoảng thời gian nhất định
    
- Tạo hiệu ứng chuyển động tự nhiên thay vì snap đột ngột
    

## Các loại Lerp trong Unity

Unity cung cấp nhiều phương thức Lerp khác nhau:

**Quaternion.Lerp**:

- Dùng cho rotation (xoay)
    
- Nội suy tuyến tính giữa 2 góc xoay
    

**Mathf.Lerp**:

- Phổ biến nhất
    
- Dùng cho số float đơn lẻ (vị trí, kích thước, etc.)
    

**Color.Lerp**:

- Dùng cho màu sắc
    
- Chuyển đổi mượt giữa các màu
    

**Quaternion.Slerp**:

- Spherical Linear Interpolation (nội suy tuyến tính cầu)
    
- Lerp theo cung tròn thay vì đường thẳng
    
- Cho hiệu ứng rotation khác biệt một chút
    

## Cú pháp Quaternion.Lerp

csharp

`Quaternion.Lerp(startRotation, endRotation, timeValue);`

3 tham số:

- **Point A** (startRotation): rotation bắt đầu
    
- **Point B** (endRotation): rotation mục tiêu
    
- **Time** (timeValue): tốc độ nội suy (0 đến 1, hoặc giá trị nhân với deltaTime)
    

## Triển khai Lerp cho Roll

Cập nhật method `ProcessRotation()`:

csharp

`void ProcessRotation() {     Quaternion targetRotation = Quaternion.Euler(         0f,          0f,          -controlRollFactor * movement.x     );          transform.localRotation = Quaternion.Lerp(         transform.localRotation,         targetRotation,         Time.deltaTime * rotationSpeed    ); }`

**Giải thích:**

- Point A: `transform.localRotation` (góc xoay hiện tại)
    
- Point B: `targetRotation` (góc xoay mục tiêu)
    
- Time: `Time.deltaTime * rotationSpeed` (tốc độ lerp)
    

## Thêm biến Rotation Speed

Ở đầu class:

csharp

`[SerializeField] float controlRollFactor = 20f; [SerializeField] float rotationSpeed = 10f;`

- Giá trị khởi tạo: 10f
    
- Có thể điều chỉnh trong Inspector để thay đổi độ mượt
    

## Cách Lerp hoạt động trong Update()

**Đặc điểm quan trọng:**

- Lerp được gọi **mỗi frame** trong Update()
    
- Mỗi frame, Point A (rotation hiện tại) thay đổi
    
- Khoảng cách từ A đến B ngày càng ngắn
    

**Hiệu ứng tạo ra:**

- Ban đầu: xoay nhanh (khoảng cách A-B lớn)
    
- Về sau: xoay chậm dần (khoảng cách A-B nhỏ dần)
    
- Tạo hiệu ứng "ease-out" tự nhiên
    

## Lerp trong Update() có đúng không?

**Câu trả lời: Có, hoàn toàn hợp lệ**

Nhiều người nghĩ đây là cách dùng "sai", nhưng:

- Không có gì sai về mặt kỹ thuật
    
- Phù hợp cho nhiều trường hợp
    
- Tạo hiệu ứng smooth và responsive
    

**Lưu ý nhỏ:**

- Có thể gặp float precision errors (lỗi độ chính xác số thực)
    
- Rotation có thể không bao giờ đạt chính xác đến target
    
- Trong trường hợp này không vấn đề gì

## So sánh trước và sau

**Trước khi dùng Lerp:**

csharp

`transform.localRotation = targetRotation; // Snap ngay lập tức`

**Sau khi dùng Lerp:**

csharp

`transform.localRotation = Quaternion.Lerp(     transform.localRotation,     targetRotation,     Time.deltaTime * rotationSpeed ); // Xoay mượt mà`

- **Pitch** (ngẩng mũi lên/xuống theo movement.y)
    
- **Yaw** (quay trái/phải)

## Ghi chú thêm

- Link tài liệu về Lerp và Slerp có trong Resources tab của khóa học
    
- [[Time.deltaTime]] đảm bảo lerp speed nhất quán trên mọi frame rate

## Code hoàn chỉnh hiện tại

csharp

`using UnityEngine; using UnityEngine.InputSystem; public class PlayerMovement : MonoBehaviour {     [SerializeField] float controlSpeed = 50f;     [SerializeField] float xClampRange = 35f;     [SerializeField] float yClampRange = 20f;          [SerializeField] float controlRollFactor = 20f;     [SerializeField] float rotationSpeed = 10f;          Vector2 movement;          void Update()     {         ProcessTranslation();         ProcessRotation();     }          public void OnMove(InputValue value)     {         movement = value.Get<Vector2>();     }          void ProcessTranslation()     {         float xOffset = movement.x * controlSpeed * Time.deltaTime;         float yOffset = movement.y * controlSpeed * Time.deltaTime;                  float rawXPos = transform.localPosition.x + xOffset;         float clampedXPos = Mathf.Clamp(rawXPos, -xClampRange, xClampRange);                  float rawYPos = transform.localPosition.y + yOffset;         float clampedYPos = Mathf.Clamp(rawYPos, -yClampRange, yClampRange);                  transform.localPosition = new Vector3(             clampedXPos,             clampedYPos,             0f         );     }          void ProcessRotation()     {         Quaternion targetRotation = Quaternion.Euler(             0f,              0f,              -controlRollFactor * movement.x         );                  transform.localRotation = Quaternion.Lerp(             transform.localRotation,             targetRotation,             Time.deltaTime * rotationSpeed        );     } }`
