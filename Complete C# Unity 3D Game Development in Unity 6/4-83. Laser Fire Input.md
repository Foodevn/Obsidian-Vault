## Tạo Hệ Thống Bắn Laser Khi Nhấn Input

## Mục tiêu bài học

- Tách logic di chuyển và vũ khí thành 2 script riêng: `PlayerMovement` và `PlayerWeapon`
    
- Sử dụng Input Actions để phát hiện hành động “fire” (bắn)
    
- Bật/tắt module **Emission** của Particle System khi nhấn/nhả nút bắn
    

---

## 1. Thiết lập Input Action “Fire”

## Tạo action mới

1. Mở asset **PlayerControls** trong thư mục **Input**
    
2. Trên action map **Player**, nhấn “+” → đặt tên **Fire**
    
3. Chọn **Action Type** = Button
    
4. Trong **Bindings**, chọn đường dẫn **Mouse → Left Button**
    

## Cấu hình interaction (tùy chọn “press and release”)

- Mục **Interactions** → nhấn “+” → chọn **Press**
    
- Ở dropdown **Trigger Behavior**, đổi thành **Press and Release**
    
    - Khi nhấn xuống: gửi event OnFire với giá trị `true`
        
    - Khi nhả: gửi event OnFire với giá trị `false`
        

Save asset

---

## 2. Tạo Script PlayerWeapon

## 2.1. Tạo file

- Trong thư mục **Scripts**, click chuột phải → Create → C# Script
    
- Đặt tên: **PlayerWeapon**
    
- Gắn component `PlayerWeapon` vào cùng GameObject có `PlayerInput` (PlayerShip)
    

## 2.2. Khai báo biến

csharp

`using UnityEngine; using UnityEngine.InputSystem; public class PlayerWeapon : MonoBehaviour {     [SerializeField] GameObject laser;      // Particle System GameObject     private bool isFiring = false;          // Trạng thái đang giữ nút bắn     // Phương thức được gọi tự động khi action Fire được kích hoạt     public void OnFire(InputValue value)     {         isFiring = value.isPressed;         // true khi nhấn, false khi nhả     }     void Update()     {         ProcessFiring();     }     void ProcessFiring()     {         var emission = laser            .GetComponent<ParticleSystem>()             .emission;                       // Lấy module Emission của ParticleSystem                  emission.enabled = isFiring;        // Bật/tắt emission theo isFiring     } }`

- `[SerializeField] GameObject laser` để kéo thả GameObject chứa Particle System
    
- `OnFire(InputValue value)` tự động sinh ra nhờ action map “Fire”
    
- `value.isPressed` trả về `true` khi giữ nút, `false` khi nhả
    
- `ProcessFiring()` chạy mỗi frame, truy xuất module `emission` và bật/tắt
    

---

## 3. Cấu hình Particle System Laser

1. Chọn GameObject **Laser** (con của PlayerShip)
    
2. Module **Emission**: giá trị Rate over Time bất kỳ (điều chỉnh sẽ set khi firing)
    
3. Module **Shape**: Radius = 0 để bắn thẳng
    
4. Module **Main**:
    
    - Looping = true
        
    - Simulation Space = World (để hạt bay độc lập)
        
5. Module **Renderer**: gán material laser đã tạo
    
6. Module **Collision** (nếu cần hủy khi chạm):
    
    - Type = World
        
    - Lifetime Loss = 1
        
    - Damping = 1
        

---

## 4. Kết quả và lưu ý

- Khi nhấn giữ nút bắn (Left Mouse Button), laser sẽ phát (emission.enabled = true)
    
- Khi nhả nút bắn, laser dừng phát (emission.enabled = false)
    
- Logic firing tách biệt hoàn toàn với logic movement
    
- Dễ mở rộng thành dual lasers hoặc thêm cơ chế cooldown
    

---

**Tiếp theo**:

- Triển khai dual lasers bằng cách dùng 2 Particle Systems hoặc Material arrays
    
- Áp dụng module interaction khác (Hold, Tap, Multi Tap) trong Input Actions để tạo hiệu ứng đặc biệt
