## Thêm Hitpoints Cho Enemy Ships

## 1. Mở Script Enemy và khai báo Hitpoints

csharp

`public class Enemy : MonoBehaviour {     [SerializeField] int hitpoints = 3;         // Số mạng ban đầu     [SerializeField] GameObject destroyedVFX;   // Prefab VFX nổ     void OnParticleCollision(GameObject other)     {         ProcessHit();     }     void ProcessHit()     {         hitpoints--;                            // Mỗi lần trúng laser trừ 1         if (hitpoints <= 0)         {             Instantiate(destroyedVFX, transform.position, Quaternion.identity);             Destroy(gameObject);         }     } }`

- `[SerializeField] int hitpoints`: mỗi prefab variant gán giá trị khác nhau
    
- `hitpoints--` là cú pháp ngắn gọn của `hitpoints = hitpoints - 1`
    
- Chỉ khi `hitpoints <= 0` mới spawn VFX và Destroy ship
    

## 2. Đảm bảo Hitpoints tương ứng sóng laser song song

- Vì bắn 2 tia đồng thời, mỗi đợt bấm sẽ trúng 2 lần
    
- Nên chọn `hitpoints` chia hết cho 2 để tránh chết hụt hoặc dư
    
    - Ví dụ: Beetle (5 hits) → hitpoints = 10
        
    - Grasshopper (1 hit) → hitpoints = 2
        
    - Wasp (2 hits) → hitpoints = 4
        
    - Butterfly (3 hits) → hitpoints = 6
        
    - Moth (2 hits) → hitpoints = 4
        

## 3. Kiểm thử

- Chạy Play Mode, bắn vào từng variant enemy
    
- Đếm số lần bắn chính xác tương ứng với `hitpoints` để thấy ship bị Destroy
    

## 4. Ghi chú về kiến trúc code

- Hiện Enemy class vừa xử lý va chạm vừa quản lý health → có dấu hiệu **code smell**
    
- Nên tách riêng thành lớp `Health` hoặc `Damageable` để tuân nguyên tắc **Single Responsibility**
    
- Lớp `Enemy` chỉ đăng ký sự kiện va chạm, gọi tới `Health.TakeDamage()`
    
- Tiếp theo sẽ tìm hiểu cách dùng **public methods** để các class giao tiếp với nhau
