## Thiết Lập Di Chuyển Cho Tàu Người Chơi

## Khái niệm xử lý di chuyển

- Trong trường hợp này không cần sử dụng [[Rigid Body]] (vật thể vật lý) vì không cần va chạm với các đối tượng vật lý khác
    
- Sử dụng phương pháp translate (dịch chuyển) trực tiếp vị trí của GameObject thông qua `transform.localPosition`
    
- `localPosition` là vị trí tương đối so với GameObject cha
    

## Thiết lập biến tốc độ di chuyển

Trong script [[PlayerMovement]], khai báo biến ở đầu class:

csharp

`[SerializeField] float controlSpeed = 10f;`

- `[SerializeField]` để hiển thị biến private trong Inspector
    
- Không cần khai báo `private` vì [[C#]] mặc định hiểu biến là private nếu không có từ khóa `public`
    
- Giá trị khởi tạo: 10f (có thể điều chỉnh sau trong Inspector)
    

## Test di chuyển cơ bản sang phải

Trong method Update(), thêm code test:

csharp

`void Update() {     float xOffset = controlSpeed * Time.deltaTime;     transform.localPosition = new Vector3(         transform.localPosition.x + xOffset,         0f,         0f     ); }`

- `Time.deltaTime` đảm bảo di chuyển độc lập với frame rate (tốc độ khung hình)
    
- Code này sẽ làm tàu tự động trượt sang phải để kiểm tra
    

## Lưu trữ giá trị Input từ Vector2

Khai báo biến cache ở đầu class:

csharp

`Vector2 movement;`

Cập nhật method OnMove():

csharp

`public void OnMove(InputValue value) {     movement = value.Get<Vector2>(); }`

- Lưu giá trị [[Vector2]] từ input vào biến `movement` để sử dụng trong Update()
    
- Method này được gọi mỗi khi phát hiện input từ action map
    

## Triển khai di chuyển trái/phải

Cập nhật xOffset trong Update():

csharp

`float xOffset = movement.x * controlSpeed * Time.deltaTime;`

- `movement.x` trả về -1 (trái) hoặc +1 (phải) hoặc 0 (không nhấn)
    
- Nhân với `controlSpeed` để điều chỉnh tốc độ
    
- Nhân với `Time.deltaTime` để đảm bảo mượt mà
    

## Điều chỉnh tốc độ trong Play Mode

- Nhấn Play
    
- Chọn GameObject PlayerAirship trong Hierarchy
    
- Trong Inspector, tìm component Player Movement
    
- Thử các giá trị:
    
    - 30: hơi chậm
        
    - 50: vừa phải, responsive (phản hồi nhanh)
        
- **Lưu ý quan trọng**: sau khi thoát Play Mode, phải set lại giá trị trong Inspector vì các thay đổi trong Play Mode không được lưu
    

## Challenge: Thêm di chuyển lên/xuống

Tương tự như xOffset, tạo yOffset:

csharp

`float yOffset = movement.y * controlSpeed * Time.deltaTime;`

Cập nhật localPosition:

csharp

`transform.localPosition = new Vector3(     transform.localPosition.x + xOffset,     transform.localPosition.y + yOffset,     0f );`

- `movement.y` trả về -1 (xuống) hoặc +1 (lên) hoặc 0 (không nhấn)
    
- Sử dụng chung `controlSpeed` để giữ tốc độ nhất quán
