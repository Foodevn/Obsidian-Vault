## Thêm Cây Vào Terrain và Xử Lý LOD, URP Compatibility

## 1. Lấy Asset Cây Từ Unity Asset Store

- Trên Unity → Window → Asset Store → tìm “trees” → lọc Free
    
- Chọn gói 1 (URP Tree Models): import về, kéo thư mục `URP_Tree_Models` vào `Assets/Imported Assets`
    
- Chọn gói 2 (Mobile Tree Pack): import về, kéo thư mục `Mobile Tree Pack` vào `Assets/Imported Assets`
    

## 2. Thiết Lập Cây URP Models

1. **Paint Trees**
    
    - Chọn Terrain → Terrain Component → tab Paint Trees → **Edit Trees → Add Tree**
        
    - Kéo prefab tree (ví dụ `Tree_Pine.prefab`) vào slot → **Add**
        
2. **Sửa Scale**
    
    - Chọn tree prefab → Inspector → Transform Scale = (6,6,6)
        
    - **Apply** prefab để scale đồng bộ
        
3. **Chỉ Hiển Thị LOD0**
    
    - Chọn tree prefab → Add Component → **LOD Group**
        
    - Mở LOD0 → Drag `Mesh Renderer` của cây vào slot Level 0
        
    - Xóa LOD1, LOD2, LOD3 → chỉ còn LOD0 để luôn hiển thị một mesh duy nhất
        

## 3. Paint Cây URP Models Lên Terrain

- Chọn Terrain → **Brush Size**, **Tree Density** thấp → paint các cây URP lên terrain
    

## 4. Sửa URP Compatibility Cho Mobile Tree Pack

- Chọn menu Unity → **Window → Render Pipeline → Render Pipeline Converter**
    
- Chọn **Material Upgrade** → Initialize Converters → Convert Assets
    
- Kiểm tra các prefab trong `Mobile Tree Pack` đã chuyển sang URP shader
    
- Nếu cần, import thêm **URP Essentials** (Project Settings → Graphics → Scriptable Render Pipeline Settings)
    

## 5. Thiết Lập Cây Mobile Pack

1. **Paint Trees**
    
    - Tương tự bước 2, Add Tree → chọn prefab từ Mobile Pack
        
2. **Scale & LOD**
    
    - Scale parent prefab (ví dụ (5,5,5)) → Apply
        
    - Thêm **LOD Group** tương tự URP Models nếu prefab chưa có LOD
        
3. Paint lên terrain cùng brush đã điều chỉnh
    

## 6. Kiểm Thử & Điều Chỉnh

- Chạy Play Mode → zoom gần/xa để kiểm tra:
    
    - Cây URP không flicker
        
    - Mobile Pack hiển thị đúng shader URP
        
- Tránh **Z-fighting** bằng cách không paint quá dày, hoặc dùng **Detail Distance** trong Terrain Settings
