## Hiển Thị Điểm Số Trên UI Canvas Với TextMeshPro

## 1. Import TextMeshPro Essentials

- Khi tạo UI → Text - TextMeshPro lần đầu, Unity yêu cầu import TMP Essentials
    
- Nếu không tự động, vào **Window → TextMesh Pro → Import TMP Essential Resources**
    

## 2. Tạo TextMeshPro UI Element

1. Hierarchy → chọn **UICanvas**
    
2. Right-click → **UI → Text - TextMeshPro** → đổi tên thành `ScoreboardText`
    
3. Chọn `ScoreboardText` → Rect Transform Anchor → **Top-Left** (Shift+Alt + click ô top-left)
    
4. Thiết lập Rect Transform:
    
    - Pos X = 10, Pos Y = −10 (cách biên trên/trái 10px)
        
    - Width đủ rộng để chứa chữ
        
5. Inspector → Text Input → gõ placeholder, ví dụ “0”
    
6. Chọn font, kích thước (Font Size ≈ 100), màu sắc phù hợp
    
7. (Tuỳ chọn) Bật **Underlay** để tạo Drop Shadow
    

## 3. Kết Nối `Scoreboard` Script Với UI Text

- Mở `Scoreboard.cs`, import namespace TMP:
    
    csharp
    
    `using TMPro; using UnityEngine; public class Scoreboard : MonoBehaviour {     int score = 0;     [SerializeField] TMP_Text scoreText;  // Kéo ScoreboardText vào đây     public void IncreaseScore(int amount)     {         score += amount;         scoreText.text = score.ToString();  // Cập nhật UI     } }`
    
- Trong Unity Editor:
    
    - Chọn GameObject `Scoreboard`
        
    - Kéo `ScoreboardText` vào trường **Score Text**
        

## 4. Kiểm Thử

1. Chạy Play Mode
    
2. Bắn và hủy enemy → hàm `IncreaseScore(int)` được gọi
    
3. Quan sát `ScoreboardText` tự động cập nhật giá trị mới
    

---

**Tóm lại**:

- Sử dụng **TextMeshPro** để hiển thị text sắc nét trên UI Canvas
    
- Anchor top-left giữ vị trí cố định trên mọi độ phân giải
    
- Gọi `scoreText.text = score.ToString()` trong public method để đồng bộ score lên UI
