## Áp Dụng Post-Processing Khác Nhau Cho Các Camera Qua Layers

## 1. Tạo Volume cho Main và Portrait

- Tạo empty GameObject `Volumes` → child:
    
    - `GlobalVolume` (layer Default) dùng cho Main Camera
        
    - `PortraitVolume` (layer Portrait) dùng cho Portrait Cameras
        
- Cả hai thêm component **Volume** →
    
    - `GlobalVolume` gán Profile chung (sample scene)
        
    - `PortraitVolume` **Create New Profile** → `PortraitVolumeProfile`
        

## 2. Định Nghĩa Layer Portrait

- **Edit → Project Settings → Tags and Layers** → User Layer 6 = `Portrait`
    
- Chọn `PortraitVolume` → Inspector → Layer = `Portrait`
    

## 3. Phân Quyền Volume Qua Layer Mask

- Chọn cả hai **Portrait Cameras** → Inspector → **Rendering → Volume Mask** = Portrait (bỏ Default)
    
- Main Camera giữ Volume Mask = Default
    

## 4. Thêm Override Riêng Cho Portrait Volume

- Chọn `PortraitVolume` → Profile → **Add Override** (Post-Processing)
    
    - Ví dụ **Film Grain**: Intensity ≈ 0.5 → hiệu ứng nhiễu màn hình cũ
        
    - (Tùy chọn) **Vignette**: tăng Intensity và Smoothness để làm tối viền
        
    - (Tùy chọn) **Color Adjustments**: giảm Saturation/Contrast cho tông “radio”
        

## 5. Kiểm Thử

- Play Scene → Main Camera và Portrait Cameras có post-processing khác nhau
    
- Portrait Cameras hiển thị grain/vignette theo profile riêng, Main giữ profile gốc
    

---

**Lưu ý**

- **Layers** giúp phân vùng Volume, Collision, Camera culling…
    
- Profile Portrait inherits Override từ Global, chỉ cần thêm Override mới hoặc override lại các setting cũ
    
- Tương tự có thể tạo nhiều Volume cho từng nhóm camera/chức năng khác nhau
