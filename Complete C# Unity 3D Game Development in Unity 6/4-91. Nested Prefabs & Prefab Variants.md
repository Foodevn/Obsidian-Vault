## Sử Dụng Prefab Variant Cho Hiệu Ứng Nổ

## Mục tiêu bài học

- Tạo hiệu ứng nổ riêng cho **player** và **enemy** bằng Prefab Variant
    
- Tránh nhân bản thủ công, tận dụng hệ thống Prefab Variant của Unity
    

---

## 1. Khái niệm Prefab Variant

- **Prefab**: template của GameObject, lưu trong thư mục Assets
    
- **Prefab Variant**: prefab con kế thừa mọi thiết lập từ prefab gốc (Parent)
    
    - Thay đổi trên Parent được đẩy xuống Variant
        
    - Thay đổi riêng trên Variant không ảnh hưởng Parent hoặc các Variant khác
        
- Hữu dụng khi có nhiều VFX tương tự nhưng khác chi tiết (màu sắc, tốc độ, scale…)
    

---

## 2. Tổ chức Prefab VFX Nổ

1. Đã có Prefab gốc `BaseDestroyedVFX` (Particle System nổ chung)
    
2. Tạo Variant cho Player:
    
    - Chuột phải lên `BaseDestroyedVFX` → **Create Prefab Variant**
        
    - Đổi tên thành `PlayerDestroyedVFX`
        
3. Tạo Variant cho Enemy:
    
    - Chuột phải lên `BaseDestroyedVFX` → **Create Prefab Variant**
        
    - Đổi tên thành `EnemyDestroyedVFX`
        
4. **Hierarchy** (test scene):
    
    - Kéo cả 3 prefab vào scene
        
    - Chỉnh sửa nhanh các tiêu chí khác nhau:
        
        - **PlayerDestroyedVFX**: Start Speed = 300, Material màu xanh
            
        - **EnemyDestroyedVFX**: Start Speed = 10, Material màu cam
            
5. Ứng dụng Override:
    
    - Mở Prefab Variant → chỉnh module, click **Overrides → Apply All** để lưu thay đổi vào Variant
        

---

## 3. Giao diện Inspector khi dùng Prefab Variant

- **Parent Prefab (`BaseDestroyedVFX`)**: icon bình thường
    
- **Variant (`PlayerDestroyedVFX`, `EnemyDestroyedVFX`)**: icon thêm sọc
    
- Khi chỉnh sửa Parent, các Variant kế thừa thay đổi tương ứng
    
- Khi chỉnh sửa Variant, chỉ áp dụng cho Variant đó
    

---

## 4. Thêm VFX nổ cho Player

Mở `CollisionHandler.cs`, thêm biến SerializedField và Instantiate:

csharp

`using UnityEngine; public class CollisionHandler : MonoBehaviour {     [SerializeField] GameObject destroyedVFX;  // Kéo PlayerDestroyedVFX vào     void OnTriggerEnter(Collider other)     {         // Spawn VFX         Instantiate(             destroyedVFX,             transform.position,             Quaternion.identity         );         Destroy(this.gameObject);     } }`

- Kéo Prefab `PlayerDestroyedVFX` vào ô **Destroyed VFX** trên component `CollisionHandler` của PlayerShip
    

---

## 5. Thêm VFX nổ cho Enemy

Mở `Enemy.cs`, thêm biến SerializedField và Instantiate:

csharp

`using UnityEngine; public class Enemy : MonoBehaviour {     [SerializeField] GameObject destroyedVFX;  // Kéo EnemyDestroyedVFX vào     void OnParticleCollision(GameObject other)     {         Instantiate(             destroyedVFX,             transform.position,             Quaternion.identity         );         Destroy(this.gameObject);     } }`

- Kéo Prefab `EnemyDestroyedVFX` vào ô **Destroyed VFX** trên component `Enemy`
    

---

## 6. Kiểm thử kết quả

- Chạy **Play Mode**
    
- Khi Player va chạm (OnTriggerEnter) → nổ xanh, PlayerShip mất
    
- Khi laser va Enemy (OnParticleCollision) → nổ cam, EnemyShip mất
    

---

## 7. Ghi chú thêm

- **Prefab Variant** giúp mở rộng và duy trì VFX nhất quán
    
- Có thể tạo Variant con-kế-thừa (Nested Variants) cho từng lớp đối tượng
    
- Sau này có thể tích hợp **Object Pooling** cho VFX để tối ưu hiệu năng
