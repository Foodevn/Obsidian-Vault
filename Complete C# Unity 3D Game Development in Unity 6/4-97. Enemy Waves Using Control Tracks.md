## Tạo & Tái Sử Dụng Enemy Waves Trên Timeline

## 1. Dọn dẹp Scene

- Xóa hết các enemy components và timelines test thừa trong Hierarchy
    
- Chỉ giữ lại: `MasterTimeline`, `PlayerRig`, và `UICanvas`
    

## 2. Tổ chức Hierarchy

- Tạo empty GameObject `Timelines`
    
    - Con của nó: empty GameObject `EnemyWaves`
        
- Kéo `MasterTimeline` vào `Timelines`
    

## 3. Tạo Prefab Wave và Timeline Riêng

1. **Tạo Wave Prefab**
    
    - Trong Hierarchy, đảm bảo chỉ chọn empty `EnemyWaves` (chưa chứa gì)
        
    - Right-click → Create empty child → đặt tên `Wave_3Butterflies`
        
    - Kéo 3 prefab `Butterfly` vào làm con của `Wave_3Butterflies`
        
    - Sắp xếp vị trí, rotation, scale sao cho tạo thành đội hình
        
2. **Tạo Timeline Cho Wave**
    
    - Chọn `Wave_3Butterflies`
        
    - Timeline Window → Plus → **Control Track**
        
    - Trong Project → Thư mục `Timelines`, click Create Timeline → đặt tên `Wave_3Butterflies.playable`
        
    - Drag file timeline mới vào Control Track của `Wave_3Butterflies`
        
3. **Animate Wave**
    
    - Lock Timeline Window, chọn tất cả 3 butterfly
        
    - Record Position track → keyframe đầu → đến cuối (7–8s) di chuyển đội hình
        
    - Chỉnh key giữa để tạo chuyển động “dip” sinh động
        
    - Stop record → Unlock
        
4. **Tạo Prefab Variant Wave**
    
    - Trong Project → Thư mục `Prefabs` → Tạo thư mục `EnemyWaves`
        
    - Kéo `Wave_3Butterflies` từ Hierarchy vào `Prefabs/EnemyWaves` → tạo Prefab
        

## 4. Tích Hợp Lên Master Timeline

1. Mở `MasterTimeline` trên `MasterTimeline` GameObject
    
2. Thêm **Control Track** mới (nếu cần)
    
3. Kéo Prefab Variant `Wave_3Butterflies` vào Control Track → tạo clip control
    
4. Di chuyển clip control để định thời điểm xuất hiện wave
    
5. Có thể tạo nhiều wave variant khác (ví dụ: `Wave_3Butterflies_2`) và kéo vào cùng hoặc track khác
    

## 5. Kiểm Thử & Tái Sử Dụng

- Play Master Timeline → wave sẽ tự động active/inactive theo clip control
    
- Kéo lại Prefab `Wave_3Butterflies` từ thư mục `EnemyWaves` vào Scene, đặt vị trí hoặc xoay để dùng lại
    
- Tạo thêm ít nhất **3 wave** khác theo mẫu:
    
    - Thay đổi số lượng, mẫu ship, đường bay
        
    - Dùng cùng workflow: prefab wave → timeline → master control
        

---

**Lưu ý**:

- Control Track cho phép bật/tắt GameObject (không phụ thuộc record clip)
    
- Có thể đặt nhiều wave trên cùng track hoặc track khác tùy tổ chức
    
- Tạo wave variant giúp linh động tái sử dụng và sắp xếp level design nhanh chóng
