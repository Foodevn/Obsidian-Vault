## Tạo VFX Nổ Khi Đối Tượng Bị Hủy

## 1. Giới thiệu Instantiation

- _Instantiation_ = khởi tạo (spawn) GameObject trong runtime
    
- Dùng để tạo hiệu ứng nổ (VFX) khi tàu hoặc enemy bị hủy
    

## 2. Chuẩn bị Prefab VFX

1. Tạo Particle System mới → đặt tên `DestroyedShipVFX`
    
2. Điều chỉnh modules:
    
    - **Renderer**: gán material tùy ý (ví dụ dùng material sao hoặc lửa)
        
    - **Shape**: Sphere để nổ tỏa đều
        
    - **Emission**: Rate over Time = 0, thêm **Burst** tại time = 0, count = 300
        
    - **Start Speed**: khoảng 50
        
    - **Noise**: Randomness cho hạt
        
    - **Duration**: 1s, **Looping** = Off
        
    - **Stop Action** = Destroy (tự hủy GameObject khi kết thúc)
        
    - **Color over Lifetime**: Fade alpha từ 100% → 0% để nổ tan dần
        
3. Drag `DestroyedShipVFX` vào thư mục `Prefabs` → tạo Prefab
    

## 3. Thay đổi Script Enemy để Instantiate VFX

Mở `Enemy.cs`, thay thế `Destroy(this.gameObject)` bằng:

csharp

`using UnityEngine; public class Enemy : MonoBehaviour {     [SerializeField] GameObject destroyedVFX;  // Prefab VFX     void OnParticleCollision(GameObject other)     {         // Instantiate explosion tại vị trí enemy         Instantiate(             destroyedVFX,             transform.position,             Quaternion.identity         );                  Destroy(this.gameObject);     } }`

- `destroyedVFX`: kéo Prefab `DestroyedShipVFX` vào Inspector
    
- `Instantiate(prefab, position, rotation)`: spawn VFX tại vị trí enemy khi trúng laser
    
- `Quaternion.identity`: không xoay
    

## 4. Gán Prefab cho Enemy

- Chọn tất cả enemy test trong Hierarchy → Lock Inspector
    
- Kéo `DestroyedShipVFX` vào ô `Destroyed VFX` của component `Enemy`
    

## 5. Kiểm thử kết quả

- Chạy Play Mode
    
- Bắn laser trúng các enemy → xuất hiện một lần hiệu ứng nổ, enemy bị Destroy
    
- Không còn loop VFX nhiều lần do đã tắt Looping trong Particle System
