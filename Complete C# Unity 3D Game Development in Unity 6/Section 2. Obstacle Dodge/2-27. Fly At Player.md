# Khái niệm Vector3

## Định nghĩa

- [[Vector3]] về cơ bản là một vị trí trong không gian thế giới
- Chứa các giá trị cho x, y, và z
- Một biến có thể chứa ba giá trị (x, y, z) trong một biến duy nhất

## Cách khai báo


```csharp
Vector3 position; // Khai báo một biến Vector3
```

## Sử dụng trong di chuyển

- Đã được sử dụng trong script move player với `transform.Translate(x, y, z)`
- Các giá trị trong ngoặc đơn tạo thành một Vector3

# Phương thức MoveTowards

## Chức năng
- [[MoveTowards]] cho phép đối tượng di chuyển về phía một điểm cụ thể trong thế giới
- Phương thức có sẵn trong Unity

## Tham số cần thiết
1. **Current**: Vị trí hiện tại (điểm xuất phát)
2. **Target**: Vị trí đích (điểm muốn di chuyển đến)
3. **Max distance delta**: Khoảng cách tối đa di chuyển mỗi lần gọi

## Cú pháp

```csharp
Vector3.MoveTowards(current, target, maxDistanceDelta);
```

## Triển khai script FlyAtPlayer

## Cấu trúc cơ bản trong Update()

```csharp
	transform.position = Vector3.MoveTowards(     
		transform.position,  // Vị trí hiện tại
		playerPosition,      // Vị trí người chơi
		1f                   // Tốc độ di chuyển
	);
```

## Khai báo biến vị trí người chơi

```csharp
Vector3 playerPosition; // Lưu trữ vị trí của người chơi
```

## Tạo tham chiếu đến người chơi
## Sử dụng SerializeField

```csharp
[SerializeField] Transform player; // Tham chiếu đến Transform của người chơi
```

## Kết nối trong Inspector

- Kéo đối tượng Player từ Hierarchy vào ô "Player" trong script component
- Tạo kết nối giữa projectile và player
- Script giờ đã "biết" đối tượng nào là người chơi

## Tại sao dùng Transform?

- Mọi [[GameObject]] đều có component Transform
- Transform component định danh loại đối tượng
- Tương tự như Light có Light component để định danh là ánh sáng

# Xác định vị trí người chơi trong Start()

## Lý do sử dụng Start() thay vì Update()

- Start(): Xác định vị trí một lần khi script khởi động
- Update(): Dùng cho "heat seeking missile" - cập nhật vị trí liên tục

## Code trong Start()



```csharp
void Start() {     
	playerPosition = player.transform.position; 
}
```

## Kiểm tra và điều chỉnh tốc độ

## Vấn đề tốc độ ban đầu

- Với giá trị 1f: Di chuyển quá nhanh (tức thời)
- Với giá trị 0.01f: Di chuyển từng frame một cách chậm chạp

## Thách thức cải tiến

Cần làm cho phương thức MoveTowards:
- **Frame rate independent**: Không phụ thuộc vào tốc độ khung hình
- **Tunable**: Có thể điều chỉnh được

## Giải pháp cải tiến

## Tạo biến tốc độ có thể điều chỉnh



```csharp
[SerializeField] float speed = 1.0f; // Biến tốc độ có thể điều chỉnh
```

## Áp dụng frame rate independence



```csharp
transform.position = Vector3.MoveTowards(     transform.position,     playerPosition,     Time.deltaTime * speed  // Sử dụng Time.deltaTime );
```

## Chia nhỏ code để dễ đọc



```csharp
transform.position = Vector3.MoveTowards(
     transform.position,
     playerPosition,
     Time.deltaTime * speed 
);
```

## Kiểm tra kết quả

## Điều chỉnh tốc độ trong Inspector

- Speed = 1: Quá chậm
- Speed = 10: Tốc độ phù hợp
- Có thể điều chỉnh cho từng đối tượng khác nhau

## Tóm tắt kỹ thuật

- **Vector3**: Vị trí trong không gian 3D (x, y, z)
- **MoveTowards**: Phương thức di chuyển về phía mục tiêu
- **SerializeField**: Hiển thị biến private trong Inspector
- **Transform reference**: Tham chiếu đến component Transform của đối tượng khác
- **Time.deltaTime**: Đảm bảo tốc độ nhất quán trên mọi thiết bị
