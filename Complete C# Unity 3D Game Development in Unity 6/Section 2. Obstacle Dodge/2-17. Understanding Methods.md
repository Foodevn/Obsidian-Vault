# Ghi chú học tập: Tổng quan về phương thức (Methods) trong lập trình

## Mục tiêu bài học
- Hiểu khái niệm phương thức (methods) hoặc hàm (functions) trong lập trình.
- Nắm cách khai báo (declare), định nghĩa (define) và gọi (call) phương thức.
- Hiểu vai trò của tham số (parameters), giá trị trả về (return values) và cú pháp cơ bản.

## Khái niệm cơ bản
- **Phương thức (Method) / Hàm (Function)**:
  - Là khối mã (block of code) thực thi một tác vụ cụ thể trong chương trình.
  - Giúp trò chơi hoặc ứng dụng thực hiện các hành động (ví dụ: di chuyển, tính toán, v.v.).
  - Thuật ngữ "method" và "function" có thể được sử dụng thay thế cho nhau trong ngữ cảnh này, dù có sự khác biệt kỹ thuật (không cần quan tâm ở giai đoạn này).
- **Ví dụ thực tế**:
  - Phương thức `CleanYourRoom` bao gồm các bước:
    - Nhặt quần áo.
    - Vứt rác.
    - Xử lý lát pizza mốc (moldy pizza).
  - Việc "gọi" phương thức tương tự như mẹ yêu cầu: "Dọn phòng đi!" – tức là thực thi các bước đã định nghĩa.

## Cú pháp khai báo phương thức
- **Cấu trúc cơ bản**:
  ```csharp
  void MethodName() {
      // Các câu lệnh (statements) thực thi;
  }
  ```
  - `void`: Kiểu trả về (return type), chỉ ra phương thức không trả về giá trị. Nếu có giá trị trả về, thay bằng kiểu dữ liệu (ví dụ: `int`, `bool`).
  - `MethodName`: Tên phương thức, tuân theo quy tắc đặt tên:
    - Viết hoa chữ cái đầu mỗi từ (PascalCase), ví dụ: `CleanYourRoom`.
    - Tên phải rõ ràng, mô tả chức năng (tránh tên chung chung như `Clean`).
  - `()`: Dấu ngoặc đơn (parentheses), chứa tham số (nếu có).
  - `{}`: Dấu ngoặc nhọn (curly braces), chứa khối mã thực thi.
  - `;`: Dấu chấm phẩy (semicolon), kết thúc mỗi câu lệnh trong khối mã.

- **Tham số (Parameters)**:
  - Là thông tin cần cung cấp khi gọi phương thức.
  - Ví dụ: `CleanYourRoom(int deadline)` yêu cầu cung cấp thời hạn (deadline) để dọn phòng.
  - Cú pháp: `type parameterName` (ví dụ: `int deadline`).
  - Có thể có nhiều tham số, cách nhau bằng dấu phẩy `,`.

- **Giá trị trả về (Return Value)**:
  - Phương thức có thể trả về dữ liệu cho nơi gọi nó.
  - Ví dụ: `CleanYourRoom` trả về `bool` (true/false) để báo phòng đã sạch hay chưa.
  - Cú pháp: Sử dụng từ khóa `return` trong khối mã, ví dụ:
    ```csharp
    bool CleanYourRoom(int deadline) {
        // Thực hiện dọn phòng
        bool isRoomDirty = false; // Kiểm tra phòng có sạch không
        return isRoomDirty; // Trả về true hoặc false
    }
    ```

- **Gọi phương thức (Calling a Method)**:
  - Cú pháp: `MethodName(arguments);`
  - `arguments`: Giá trị cụ thể truyền vào để đáp ứng tham số.
  - Ví dụ: `CleanYourRoom(60);` – dọn phòng trong 60 phút.
  - Nếu không có tham số, để trống: `MethodName();`.

## Ví dụ minh họa
### Khai báo và định nghĩa phương thức
```csharp
bool CleanYourRoom(int deadline) {
    // Nhặt quần áo
    // Vứt rác
    // Xử lý pizza mốc
    bool isRoomDirty = false; // Phòng đã sạch
    return isRoomDirty; // Trả về trạng thái phòng
}
```

### Gọi phương thức
```csharp
bool result = CleanYourRoom(60); // Gọi phương thức với thời hạn 60 phút
if (result) {
    // Phòng vẫn bẩn, tiếp tục gọi CleanYourRoom
} else {
    // Phòng sạch, dừng lại
}
```

## Phương thức trong Unity
- **Phương thức đặc biệt**:
  - `Start` và `Update` là các phương thức callback, được Unity tự động gọi:
    - `Start`: Gọi một lần khi đối tượng game (game object) được kích hoạt.
    - `Update`: Gọi liên tục mỗi khung hình (frame).
  - Không cần gọi thủ công, Unity xử lý theo thứ tự thực thi (order of execution).
- **Vai trò**:
  - Người lập trình chỉ cần định nghĩa nội dung trong `Start` hoặc `Update`.
  - Ví dụ:
    ```csharp
    void Start() {
        // Khởi tạo đối tượng khi bắt đầu
    }

    void Update() {
        // Cập nhật trạng thái mỗi khung hình
    }
    ```

## Ghi chú thêm
- **Tham số và đối số (Parameters vs Arguments)**:
  - Tham số (parameter): Biến được khai báo trong định nghĩa phương thức (ví dụ: `int deadline`).
  - Đối số (argument): Giá trị cụ thể truyền vào khi gọi phương thức (ví dụ: `60`).
- **Tầm quan trọng của cú pháp**:
  - Không bỏ sót dấu chấm phẩy `;` khi gọi phương thức hoặc trong khối mã.
  - Đảm bảo kiểu dữ liệu của tham số và giá trị trả về khớp nhau (ví dụ: không trả về `float` khi khai báo `int`).
- **Ứng dụng thực tế**:
  - Hiểu cú pháp phương thức giúp đọc và sử dụng code từ diễn đàn hoặc AI dễ dàng hơn.
  - Các khái niệm như tham số, giá trị trả về sẽ được áp dụng nhiều trong các dự án lập trình.
