## Tạo script quay vật thể (Spinner Script)

Bài học này hướng dẫn tạo script làm cho các vật thể quay tròn liên tục, mở rộng hệ thống chướng ngại vật trong game với thêm một loại obstacle động.[huihoo+1](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)

## Tạo đối tượng mới và cấu hình cơ bản

**Tạo Cube quay**:
- Right-click trong Hierarchy → 3D Object → Cube
- Đặt ở vị trí trung tâm, dễ nhìn thấy
- Nhấn F để zoom vào object
- Dùng R (Scale tool) để điều chỉnh kích thước phù hợp
- Dùng E (Rotation tool) để test xem hướng quay như thế nào
- Di chuyển xuống gần mặt đất để tạo cảm giác đe dọa

**Thêm các script cần thiết**:

- Kéo script [[ObjectHit]] vào cube (để xử lý va chạm và đổi màu)
- Tạo script mới tên "Spinner" cho chức năng quay
- Đổi tên GameObject thành "Spinning Thing" (tên dễ hiểu hơn "Cube")
- Sắp xếp vào group Environment để dễ quản lý

## Tạo Material cho đối tượng quay

- Right-click → Create → Material, đặt tên "Spinner Color"
- Kéo material lên đối tượng để áp dụng
- Chọn màu tối (ví dụ: màu xanh đậm) để phù hợp với theme tối
- Material này có thể tái sử dụng cho các spinner khác

## Hiểu về Transform.Rotate

[[Transform.Rotate]] là phương thức để xoay GameObject trong Unity:[unity3d+1](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)
- Hoạt động tương tự [[Transform.Translate]] nhưng cho rotation thay vì movement[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)
- Nhận tham số là góc quay theo các trục x, y, z (tính bằng degrees)[unity3d](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)
- Trục Y (màu xanh lá) là trục dọc, thường dùng để quay ngang[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)
- Quay quanh trục Y tạo hiệu ứng spin tự nhiên nhất cho hầu hết objects[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)

## Viết code cơ bản cho Spinner

Trong script Spinner.cs:[unity3d+1](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)


```csharp
void Update() 
{     
	transform.Rotate(1, 1, 1); 
}
```

**Giải thích**:

- Mỗi frame, object sẽ quay 1 degree theo cả 3 trục[unity3d](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)
- Tham số (1, 1, 1) có nghĩa: xAngle = 1, yAngle = 1, zAngle = 1[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)
- Quay theo cả 3 trục tạo hiệu ứng "bananas" - rất hỗn loạn và khó đoán[unity3d](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)

**Thử nghiệm với các giá trị khác**:[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)

```csharp
transform.Rotate(0, 1, 0);  // Chỉ quay quanh trục Y
```

Điều này tạo hiệu ứng quay ngang đều đặn, dễ nhìn hơn.[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)

## Vấn đề với Magic Numbers

Hard-code các giá trị (1, 1, 1) hoặc (0, 1, 0) gây ra những vấn đề:[unity3d](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)
- Khó điều chỉnh tốc độ quay khi đã compile
- Không thể tái sử dụng script cho objects khác với tốc độ khác nhau
- Không thể thay đổi trục quay mà không sửa code
- Không thể fine-tune trong Inspector

## Sử dụng biến SerializeField

Thay thế magic numbers bằng các biến có thể điều chỉnh:[unity3d](https://docs.unity3d.com/ScriptReference/Transform.Rotate.html)



```csharp
[SerializeField] float xAngle = 0f; 
[SerializeField] float yAngle = 0f; 
[SerializeField] float zAngle = 0f; 
void Update() 
{     
	transform.Rotate(xAngle, yAngle, zAngle); 
}
```

**Lợi ích**:[huihoo](https://docs.huihoo.com/unity/5.5/Documentation/ScriptReference/Transform.Rotate.html)

- Có thể điều chỉnh tốc độ quay trực tiếp trong Inspector
- Mỗi object có thể có tốc độ và hướng quay khác nhau
- Dễ dàng tạo ra các hiệu ứng quay đa dạng
- Code tái sử dụng được cho nhiều objects

## Điều chỉnh giá trị trong Inspector

**Các giá trị gợi ý**:[steemit+1](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)
- Y Angle = 0.5: Quay ngang với tốc độ vừa phải
- Y Angle = 3: Quay nhanh, có thể quá nhanh cho gameplay
- X Angle = 2: Tạo hiệu ứng lật đầu lật đuôi
- Kết hợp nhiều trục tạo chuyển động phức tạp

**Quá trình fine-tuning**:

- Test trong Play mode để xem tốc độ
- Stop game, điều chỉnh giá trị
- Chạy lại để kiểm tra
- Lặp lại cho đến khi hài lòng

## Performance và Time.deltaTime

**Lưu ý về hiệu suất**:[steemit+1](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)
- Code hiện tại quay với tốc độ phụ thuộc vào framerate
- Để quay đều trên mọi thiết bị, nên nhân với [[Time.deltaTime]]:[steemit](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)

```csharp
transform.Rotate(xAngle * Time.deltaTime, yAngle * Time.deltaTime, zAngle * Time.deltaTime);
```

**Ý nghĩa**:[steemit](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)

- [[Time.deltaTime]] đảm bảo chuyển động đều đặn bất kể framerate[steemit](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)
- Giá trị angles lúc này sẽ là degrees per second thay vì degrees per frame[steemit](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)
- Quan trọng cho game được chơi trên nhiều thiết bị khác nhau[steemit](https://steemit.com/tutorial/@chrs944/unity-simple-2d-rotation-script)

## Ghi chú về game design

Spinner objects tạo thêm thử thách cho player:

- Buộc player phải timing chính xác khi đi qua
- Tăng độ khó mà không cần thêm enemies
- Tạo visual interest cho môi trường game
- Có thể kết hợp với dropping objects để tạo combo challenges
