## Sao chép đối tượng

- Sử dụng Ctrl+D để tạo bản sao (duplicate) của projectile
- Di chuyển từng bản sao sang vị trí khác nhau
- Tạo thêm một vài bản sao để thử nghiệm

## Điều chỉnh tốc độ khác nhau

- Chọn từng game object
- Thay đổi giá trị Speed trong component Fly at Player
- Mỗi đối tượng sẽ có tốc độ bay khác nhau về phía người chơi

## Vấn đề cần giải quyết

## Hiện tượng không mong muốn

- Khi projectile đến đích, chúng vẫn còn tồn tại trong game
- Có thể di chuyển người chơi xung quanh nhưng các đối tượng vẫn ở đó

## Tại sao cần hủy đối tượng?

- Nếu có 100, 1000 hay hàng vạn đối tượng như đạn bắn
- [[Hierarchy]] sẽ bị đầy lên
- Game phải ghi nhớ vị trí và thông tin của tất cả đối tượng không cần thiết
- Ảnh hưởng hiệu suất game

## Triển khai hủy đối tượng

## Nguyên tắc

Khi đối tượng đã hoàn thành mục đích → **Hủy ngay lập tức**

## Tạo phương thức hủy đối tượng



```csharp
void DestroyWhenReached() {
     if (transform.position == playerPosition)     
    {
            Destroy(gameObject);     
    } 
}
```


## Gọi phương thức trong Start()


```csharp
void Start() {     
	playerPosition = player.transform.position;     
	DestroyWhenReached(); // CÁCH KHÔNG ĐÚNG! 
}
```

## Sửa lỗi logic

## Vấn đề với việc gọi trong Start()

- Start() chỉ chạy một lần khi bắt đầu
- Lúc đó đối tượng chưa đến đích
- Sẽ hủy đối tượng ngay lập tức - không mong muốn

## Giải pháp đúng: Gọi trong Update()

```csharp
void Update() {     
	MoveToPlayer();     
	DestroyWhenReached(); 
}
```

## Kiểm tra điều kiện đã đến đích

## Sử dụng if statement



```csharp
if (transform.position == playerPosition) {
     Destroy(gameObject); 
    }
```

## Giải thích code

- `transform.position`: Vị trí hiện tại của đối tượng
- `==`: So sánh bằng nhau
- `playerPosition`: Vị trí đích (vị trí người chơi)
- `Destroy(gameObject)`: Hủy chính đối tượng này

## Tái cấu trúc code (Refactoring)

## Tạo phương thức MoveToPlayer riêng biệt


```csharp
void MoveToPlayer() {
     transform.position = Vector3.MoveTowards(
        transform.position,
        playerPosition,
        Time.deltaTime * speed    
    ); 
}
```

## Cập nhật Update() method

```csharp
void Update() {     MoveToPlayer();     DestroyWhenReached(); }
```

## Cấu trúc code hoàn chỉnh



```csharp
[SerializeField] Transform player;
    [SerializeField] float speed = 1.0f;
    Vector3 playerPosition;
    void Start()
    {
        playerPosition = player.transform.position;
    }
    void Update()
    {
        MoveToPlayer(); DestroyWhenReached();
    }
    void MoveToPlayer()
    {
       transform.position = Vector3.MoveTowards(transform.position, playerPosition, Time.deltaTime * speed);
    }
    void DestroyWhenReached()
    {
        if (transform.position == playerPosition)
        {
            Destroy(gameObject);
        }
    }
```

## Hành vi mong đợi

- Tất cả projectile bay về phía người chơi với tốc độ khác nhau

## Lý do quan trọng

- So sánh với vị trí đích chứ không phải va chạm với người chơi
- Người chơi có thể di chuyển tránh, nhưng đối tượng vẫn đến đúng điểm đích ban đầu

## Nguyên tắc thiết kế

**"Khi không còn sử dụng → Hủy ngay lập tức"**

Đây là nguyên tắc quan trọng trong phát triển game để đảm bảo hiệu suất và quản lý tài nguyên hiệu quả.

## Ghi chú kỹ thuật

- **Destroy(gameObject)**: Hủy đối tượng hiện tại
- **Update() vs Start()**: Update() chạy mỗi frame, Start() chỉ chạy một lần
- **Refactoring**: Chia code thành các phương thức nhỏ để dễ quản lý
- **Object lifecycle**: Quản lý vòng đời của đối tượng từ tạo đến hủy
