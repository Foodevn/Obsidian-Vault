## Kích hoạt projectile khi người chơi đi qua Trigger Volume

## Tạo Trigger Volume

- Trong **Hierarchy**: chuột phải → Create → 3D Object → Cube
- Đặt Cube trước mặt người chơi, điều chỉnh vị trí và kích thước cho phù hợp
- Tắt **Mesh Renderer** để Trigger Volume trở nên vô hình
- Trong **Box Collider** của Cube, tích chọn **Is Trigger**

## Viết script “TriggerProjectile”

```csharp
using UnityEngine;

public class TriggerProjectile : MonoBehaviour
{
    [SerializeField] GameObject projectile1;
    [SerializeField] GameObject projectile2;
    [SerializeField] GameObject projectile3;
    [SerializeField] GameObject projectile4;
    [SerializeField] GameObject projectile5;

    void OnTriggerEnter(Collider other)
    {
        if (other.gameObject.tag.Equals("Player"))
        {
            projectile1.SetActive(true);
            projectile2.SetActive(true);
            projectile3.SetActive(true);
            projectile4.SetActive(true);
            projectile5.SetActive(true);
        }
    }
}
```

## Giải thích

- **[SerializeField] GameObject projectileX**: Tham chiếu đến các prefab projectile (tắt sẵn)
- **OnTriggerEnter(Collider other)**: Phát hiện khi “Player” đi qua Trigger
- Trong khối `if`: gọi `SetActive(true)` để “đánh thức” từng projectile, kích hoạt FlyAtPlayer script

## Cấu hình trong Inspector

1. Gắn script **TriggerProjectile** vào Trigger Volume
2. Kéo thả lần lượt 5 đối tượng projectile vào các ô tương ứng
3. Đảm bảo các projectile đã tắt sẵn (`Set Active = false`) trong Hierarchy

## Quy trình hoạt động

1. Người chơi chạm vào Trigger Volume
2. `OnTriggerEnter` kiểm tra tag “Player”
3. Tất cả projectile được bật lên
4. Mỗi projectile chạy FlyAtPlayer và bay về phía người chơi

## Lưu ý quan trọng

- Phải kích hoạt **Is Trigger** trên Collider của Trigger Volume
- Người chơi cần có **Rigidbody** để Trigger hoạt động
- Đây là cách đơn giản, có thể mở rộng bằng cách dùng mảng hoặc danh sách (`List<GameObject>`) để quản lý nhiều projectile hơn

## Thử thách tiếp theo

- Tạo mảng `GameObject[] projectiles` để quản lý động số lượng projectile
- Khi kích hoạt, dùng vòng lặp `foreach` để bật tất cả
- Nâng cấp logic để projectile chỉ kích hoạt tuần tự hoặc theo từng đợt
- Kết hợp với hiệu ứng âm thanh hoặc hạt particle khi projectile xuất hiện
