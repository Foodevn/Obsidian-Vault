# Ghi chú học tập: Start và Update trong Unity - Di chuyển Game Object

## Tổng quan
- **Mục tiêu**: 
  - Hiểu sự khác biệt giữa hàm `Start()` và `Update()` trong Unity.
  - Viết mã C# cơ bản để di chuyển một game object (người chơi) trên màn hình.
  - Thực hành tạo dự án, thêm game objects, và cấu hình cơ bản.
- **Dự án**: Obstacle Dodge
- **Gợi ý liên kết**: [[Start and Update]], [[C# Basics]], [[Obstacle Dodge]]

## Nội dung chi tiết

### 1. Thử thách: Thiết lập dự án Obstacle Dodge
- **Yêu cầu**:
  - Tạo một dự án Unity mới với **Universal 3D Pipeline**.
  - Thêm một mặt phẳng (plane) làm mặt đất (ground).
  - Thêm một hình khối (cube) làm người chơi (player) và đặt tên sáng tạo (ví dụ: **Dodgy**).
- **Hướng dẫn**:
  - **Tạo dự án**:
    - Mở **Unity Hub** → **Projects** → **New Project**.
    - Chọn **Unity 6** và mẫu **Universal 3D** (phù hợp cho các dự án prototype, không cần đồ họa cao cấp như High Definition Render Pipeline).
    - Đặt tên dự án: **Obstacle Dodge**.
    - Chọn thư mục lưu trữ, tắt **Unity Cloud** → Nhấn **Create Project**.
  - **Xóa tài nguyên mẫu**:
    - Trong Unity, nếu thấy nút **Remove Readme Assets** trong **Inspector**, nhấn **Proceed** để xóa các tài nguyên mẫu không cần thiết.
  - **Thêm mặt đất (Ground)**:
    - Trong **Hierarchy**, nhấp chuột phải → **3D Object** → **Plane**.
    - Đổi tên thành **Ground**.
    - Nhấn **R** (Scale Tool) để tăng kích thước mặt phẳng (ví dụ: mở rộng theo trục X và Z).
  - **Thêm người chơi (Player)**:
    - Nhấp chuột phải → **3D Object** → **Cube**.
    - Đổi tên thành **Dodgy** (hoặc tên sáng tạo khác).
    - Nhấn **R** để điều chỉnh tỷ lệ, làm phẳng cube để trông thú vị hơn.
  - **Di chuyển Global Volume**:
    - Kéo **Global Volume** ra khỏi khu vực làm việc để tránh gây nhiễu.
- **Gợi ý liên kết**: [[Unity Project Setup]], [[Game Objects]], [[Universal Render Pipeline]]

### 2. Tạo và áp dụng Materials
- **Mô tả**: Tạo vật liệu (materials) để phân biệt mặt đất và người chơi.
- **Hướng dẫn**:
  - Trong **Project** → Nhấp chuột phải → **Create** → **Material** → Đặt tên **DarkColor**.
    - Trong **Inspector**, nhấp vào **Base Map** → Chọn màu tối (ví dụ: xám đậm).
    - Giảm **Smoothness** về 0 để tạo hiệu ứng mờ (matte), tránh bóng sáng.
    - Kéo **DarkColor** vào **Ground** trong **Hierarchy** hoặc **Scene**.
  - Tạo material thứ hai → Đặt tên **Green**.
    - Chọn màu xanh đặc trưng (Game Dev TV green) bằng mã hex (ví dụ: nhập mã hex vào **Color Picker**).
    - Kéo **Green** vào **Dodgy** (người chơi).
  - **Tổ chức tài nguyên**:
    - Tạo thư mục **Materials** trong **Project** → Kéo cả **DarkColor** và **Green** vào.
    - Tạo thư mục **Scripts** để lưu script sau này.
- **Gợi ý liên kết**: [[Materials]], [[Base Map]], [[Asset Organization]]

### 3. Tạo và gắn Script
- **Mô tả**: Tạo script C# để điều khiển chuyển động của người chơi.
- **Hướng dẫn**:
  - Trong **Project** → Thư mục **Scripts** → Nhấp chuột phải → **Create** → **C# Script**.
  - Đặt tên **Mover** trước khi nhấp ra ngoài (tránh tên mặc định).
  - Gắn script vào **Dodgy**:
    - Kéo **Mover** từ **Project** vào **Dodgy** trong **Hierarchy**.
    - Hoặc chọn **Dodgy** → **Add Component** → Tìm **Mover** → Nhấn để thêm.
    - Hoặc kéo **Mover** vào vùng trống trong **Inspector** của **Dodgy**.
  - Nhấp đúp vào **Mover** để mở trong Visual Studio Code.
- **Gợi ý liên kết**: [[C# Script Creation]], [[MonoBehaviour]], [[Component Attachment]]

### 4. Hiểu về `Start()` và `Update()`
- **Hàm `Start()`**:
  - Được gọi **một lần** khi game object (có script gắn vào) được kích hoạt, ngay khi nhấn **Play**.
  - Dùng để khởi tạo (initialization) hoặc thiết lập ban đầu.
- **Hàm `Update()`**:
  - Được gọi **mỗi khung hình (frame)** trong suốt thời gian game chạy.
  - Một khung hình (frame) là một lần tính toán trạng thái game (ví dụ: 60 khung hình/giây → 60 lần Update mỗi giây).
  - Dùng để xử lý các hành động liên tục, như di chuyển, cập nhật trạng thái.
- **Ví dụ**:
  - `Start()`: Thiết lập vị trí ban đầu của người chơi.
  - `Update()`: Di chuyển người chơi liên tục mỗi khung hình.
- **Gợi ý liên kết**: [[Start Function]], [[Update Function]], [[Frame Rate]]

### 5. Viết mã di chuyển Game Object
- **Mô tả**: Viết mã trong script **Mover** để di chuyển **Dodgy** sang phải.
- **Hướng dẫn**:
  - Mở script **Mover** trong Visual Studio Code.
  - Trong hàm `Start()`, thêm dòng mã:
    ```csharp
    transform.Translate(1f, 0f, 0f);
    ```
    - **Giải thích**:
      - `transform`: Truy cập **Transform Component** của game object (vị trí, xoay, tỷ lệ).
      - `.Translate()`: Phương thức di chuyển game object.
      - `(1f, 0f, 0f)`: Di chuyển 1 đơn vị theo trục X, 0 theo trục Y và Z.
      - `f`: Chỉ định số thực kiểu **float** (Unity yêu cầu float thay vì double).
  - Lưu script (**Ctrl+S** hoặc **Cmd+S**).
  - Trong Unity, nhấn **Play** → **Dodgy** di chuyển 1 đơn vị sang phải (chỉ một lần).
  - Di chuyển mã từ `Start()` sang `Update()`:
    ```csharp
    void Update()
    {
        transform.Translate(1f, 0f, 0f);
    }
    ```
    - Nhấn **Play** → **Dodgy** di chuyển liên tục sang phải, nhưng quá nhanh (1 đơn vị mỗi khung hình).
  - Giảm tốc độ bằng cách thay đổi:
    ```csharp
    transform.Translate(0.01f, 0f, 0f);
    ```
    - Kết quả: **Dodgy** di chuyển chậm hơn, mượt mà hơn (0.01 đơn vị mỗi khung hình).
- **Lưu ý**:
  - Luôn lưu script trước khi chạy trong Unity để áp dụng thay đổi.
  - Nếu gặp lỗi (ví dụ: squiggly lines), kiểm tra kiểu dữ liệu (float cần `f`).
  - Khi nhấn **Stop**, game object trở về vị trí ban đầu (thay đổi trong Play Mode không được lưu).
- **Gợi ý liên kết**: [[Transform Component]], [[Translate Method]], [[Float vs Double]]

### 6. Điều chỉnh Camera
- **Mô tả**: Đặt lại vị trí camera để quan sát **Dodgy** rõ ràng.
- **Hướng dẫn**:
  - Chọn **Main Camera** trong **Hierarchy**.
  - Nhấn **F** để tập trung vào camera trong **Scene View**.
  - Sử dụng **W** (Move Tool) để di chuyển camera đến gần **Dodgy**.
  - Sử dụng **E** (Rotate Tool) để xoay camera hướng xuống **Dodgy**.
  - Kiểm tra trong **Game View** để đảm bảo camera hiển thị đúng góc nhìn người chơi.
- **Gợi ý liên kết**: [[Camera Setup]], [[Game View]]
