# Ghi chú học tập: Biến (Variables) trong Unity và Điều chỉnh chuyển động

## Tổng quan
- **Mục tiêu**:
  - Hiểu khái niệm biến (variables) trong lập trình C# và cách sử dụng trong Unity.
  - Tạo biến để thay thế các giá trị cố định (hard-coded) trong mã.
  - Thay đổi chuyển động của game object để bay thẳng lên trên (theo trục Y).
- **Dự án**: Obstacle Dodge
- **Gợi ý liên kết**: [[Variables]], [[C# Basics]], [[Obstacle Dodge]]

## Nội dung chi tiết

### 1. Khái niệm biến (Variables)
- **Mô tả**:
  - Biến là "hộp" dùng để **lưu trữ**, **thao tác**, và **tham chiếu** thông tin.
  - Mỗi biến có:
    - **Tên** (ví dụ: `hitpoints`).
    - **Dữ liệu** (ví dụ: giá trị `20`).
    - **Kiểu dữ liệu** (ví dụ: `int`, `float`, `bool`, `string`).
- **Các kiểu dữ liệu phổ biến**:
  - **int (integer)**: Số nguyên (ví dụ: `20`, `30`, `52`).
    - Cú pháp: `int hitpoints = 20;`
    - Quy ước đặt tên: Chữ cái đầu viết thường, các từ tiếp theo viết hoa chữ đầu (camelCase), ví dụ: `hitPoints`.
  - **float (floating-point)**: Số thập phân, cần thêm `f` ở cuối giá trị.
    - Ví dụ: `float speed = 5.5f;`
  - **bool (boolean)**: Giá trị `true` hoặc `false`, thường dùng để kiểm tra trạng thái (ví dụ: `isAlive`, `isActive`).
    - Ví dụ: `bool isAlive = true;`
  - **string**: Chuỗi ký tự (chữ, số, ký hiệu), được bao quanh bởi dấu nháy kép (`"`).
    - Ví dụ: `string playerName = "Rick";`
- **Lợi ích của biến**:
  - **Tính linh hoạt**: Dễ dàng thay đổi giá trị ở một nơi mà không cần sửa nhiều dòng mã.
  - **Tổ chức mã**: Nhóm các giá trị quan trọng ở đầu script, dễ quản lý.
  - **Tránh lỗi**: Giảm nguy cơ sai sót khi phải sửa giá trị cố định ở nhiều nơi.
- **Gợi ý liên kết**: [[Variable Types]], [[C# Naming Conventions]]

### 2. Thay thế giá trị cố định bằng biến
- **Mô tả**: Thay giá trị cố định `0.01f` trong script `Mover` bằng biến để điều khiển chuyển động.
- **Hướng dẫn**:
  - Mở script **Mover** trong Visual Studio Code.
  - Thêm biến ở đầu script (trên hàm `Start()`):
    ```csharp:disable-run
    float xValue = 0.01f;
    ```
    - **Giải thích**:
      - `float`: Kiểu dữ liệu cho số thập phân.
      - `xValue`: Tên biến (theo quy ước camelCase).
      - `0.01f`: Giá trị khởi tạo, dùng `f` để chỉ định kiểu float.
      - `;`: Kết thúc câu lệnh.
  - Sửa hàm `Update()`:
    ```csharp
    void Update()
    {
        transform.Translate(xValue, 0f, 0f);
    }
    ```
    - Thay `0.01f` bằng `xValue` để sử dụng giá trị từ biến.
  - Lưu script (**Ctrl+S** hoặc **Cmd+S**).
  - Trong Unity, nhấn **Play** → Kiểm tra **Dodgy** di chuyển sang phải như trước, xác nhận biến hoạt động đúng.
- **Lợi ích**:
  - Chỉ cần thay đổi giá trị của `xValue` ở đầu script để điều chỉnh tốc độ mà không cần sửa nhiều chỗ.
- **Gợi ý liên kết**: [[Transform Translate]], [[Float Variables]]

### 3. Thử thách: Tạo biến cho Y, Z và Bay lên trên
- **Yêu cầu**:
  - Tạo hai biến mới: `yValue` và `zValue`.
  - Điều chỉnh giá trị để **Dodgy** bay thẳng lên trên (theo trục Y) thay vì sang phải.
- **Hướng dẫn**:
  - Thêm hai biến mới vào script **Mover** (trên hàm `Start()`):
    ```csharp
    float yValue = 0.05f;
    float zValue = 0f;
    ```
    - Khởi tạo `yValue = 0.05f` để di chuyển lên trên.
    - Giữ `zValue = 0f` vì không di chuyển theo trục Z.
  - Sửa biến `xValue`:
    ```csharp
    float xValue = 0f;
    ```
    - Đặt `xValue = 0f` để ngừng di chuyển ngang.
  - Cập nhật hàm `Update()`:
    ```csharp
    void Update()
    {
        transform.Translate(xValue, yValue, zValue);
    }
    ```
    - Sử dụng cả ba biến theo thứ tự X, Y, Z.
  - Lưu script và nhấn **Play** trong Unity → **Dodgy** bay thẳng lên trên với tốc độ 0.05 đơn vị mỗi khung hình.
- **Lưu ý**:
  - Thứ tự trong `Translate(x, y, z)` phải đúng: X (đỏ), Y (xanh lá), Z (xanh dương).
  - Trục Y là trục thẳng đứng trong Unity (xem widget trong **Scene View**).
  - Giá trị `0.05f` tạo chuyển động nhanh hơn `0.01f` để dễ quan sát.
- **Gợi ý liên kết**: [[Axis System]], [[Game Object Movement]]

### 4. Kiểm tra và debug
- **Kiểm tra trong Unity**:
  - Nhấn **Play** để xem **Dodgy** di chuyển lên trên.
  - Nếu không di chuyển đúng, kiểm tra:
    - Đã lưu script chưa (**Ctrl+S**).
    - Giá trị biến có đúng không (ví dụ: `yValue` phải khác 0).
    - Thứ tự tham số trong `Translate()` có đúng không.
- **Sửa lỗi kiểu dữ liệu**:
  - Nếu gặp lỗi "cannot convert from double to float" (gạch đỏ dưới số), thêm `f` vào giá trị (ví dụ: `0.05` → `0.05f`).
  - Unity yêu cầu sử dụng `float` (ít chính xác hơn `double`) cho hầu hết các phép tính.
- **Gợi ý liên kết**: [[Debugging in Unity]], [[Float vs Double]]
