# Ghi chú học tập: Thiết lập điều khiển bàn phím sử dụng hệ thống Input trong Unity

## Tổng quan
Bài giảng này hướng dẫn cách thiết lập điều khiển bàn phím để di chuyển nhân vật theo các hướng trái, phải, lên, xuống trong Unity, sử dụng **hệ thống input cũ (old input system)** để thay đổi vị trí thủ công. Nội dung tập trung vào việc triển khai một cảnh di chuyển đơn giản, phù hợp cho người mới bắt đầu.

---

## Nội dung chính

### 1. Giới thiệu về hệ thống Input trong Unity
- Unity hỗ trợ hai hệ thống input:
  - **Hệ thống input cũ (Old Input System)**: Đơn giản, dễ sử dụng, phù hợp cho người mới.
  - **Hệ thống input mới (New Input System)**: Mạnh mẽ hơn, nhưng phức tạp và cần cấu hình nhiều hơn.
- Trong dự án này, sử dụng **hệ thống input cũ** để thay đổi vị trí nhân vật thủ công (manual position changes) thay vì sử dụng lực vật lý (physics-based force).
- Mục tiêu: Di chuyển nhân vật trên mặt phẳng (x, z) bằng các phím điều khiển.

---

### 2. Cấu hình Input Manager trong Unity
- **Truy cập Input Manager**:
  - Vào **Edit > Project Settings > Player > Other Settings**.
  - Kiểm tra **Active Input Handling**:
    - Nếu là **New Input System**, chuyển về **Old Input System** và khởi động lại Unity.
    - Nếu không thấy tùy chọn này, Unity đang mặc định sử dụng hệ thống input cũ.
- Trong **Input Manager** (trong Project Settings):
  - **Horizontal Axis (trục ngang)**: Điều khiển trái/phải, sử dụng phím **A/D** hoặc **mũi tên trái/phải**.
  - **Vertical Axis (trục dọc)**: Điều khiển lên/xuống, sử dụng phím **W/S** hoặc **mũi tên lên/xuống**.
- Các trục này đã được thiết lập sẵn, dễ dàng sử dụng trong mã code.

---

### 3. Cách thực hiện: Cập nhật mã code để điều khiển di chuyển
- **Vị trí ban đầu của biến**:
  - Các biến điều khiển vị trí (`xValue`, `yValue`, `zValue`) ban đầu được khai báo bên ngoài hàm `Update()`.
  - Để cập nhật vị trí mỗi khung hình, chuyển các biến này vào hàm `Update()`.

- **Loại bỏ SerializeField**:
  - Vì các biến được điều khiển động bởi bàn phím, không cần `[SerializeField]` để nhập giá trị thủ công trong Unity Editor.

- **Mã code điều khiển trục ngang (Horizontal)**:
  - Sử dụng `Input.GetAxis("Horizontal")` để lấy giá trị từ các phím trái/phải:
    ```csharp:disable-run
    xValue = Input.GetAxis("Horizontal");
    ```
  - Lưu ý: Chuỗi `"Horizontal"` phải được viết chính xác, phân biệt chữ hoa/thường.

- **Mã code điều khiển trục dọc (Vertical)**:
  - Sử dụng `Input.GetAxis("Vertical")` để lấy giá trị từ các phím lên/xuống:
    ```csharp
    zValue = Input.GetAxis("Vertical");
    ```
  - Vì di chuyển trên mặt phẳng, đặt `yValue = 0` để ngăn nhân vật bay lên.

- **Kết quả mã code hoàn chỉnh trong hàm Update**:
  ```csharp
  void Update() {
      float xValue = Input.GetAxis("Horizontal");
      float yValue = 0f;
      float zValue = Input.GetAxis("Vertical");
      // Code để cập nhật vị trí nhân vật
  }
  ```

---

### 4. Kết quả và vấn đề
- **Kết quả**:
  - Nhân vật di chuyển trái/phải (trục x) và lên/xuống (trục z) khi nhấn các phím tương ứng.
  - Nếu `yValue` không được đặt về 0, nhân vật có thể "bay" lên do giá trị y không được kiểm soát.

- **Vấn đề**:
  - Di chuyển quá nhanh, cần điều chỉnh tốc độ trong bài tiếp theo bằng cách sử dụng `Time.deltaTime` và một biến tốc độ (speed variable).

---

### 5. Ghi chú thêm
- **Liên kết chéo**:
  - Xem thêm về [[Time.deltaTime]] để kiểm soát tốc độ di chuyển.
  - Tham khảo [[Input Manager]] trong Unity Documentation để tìm hiểu sâu hơn về các trục và phím.
- **Mẹo thực hành**:
  - Kiểm tra kỹ chính tả của `"Horizontal"` và `"Vertical"` trong mã code để tránh lỗi.
  - Nếu sử dụng hệ thống input mới, cần cấu hình thêm trong **Input Action Assets** (xem [[New Input System]]).

---

## Tóm tắt
- Bài giảng hướng dẫn sử dụng **hệ thống input cũ** trong Unity để điều khiển di chuyển nhân vật.
- Sử dụng `Input.GetAxis("Horizontal")` và `Input.GetAxis("Vertical")` để lấy đầu vào từ bàn phím.
- Cần đặt `yValue = 0` để giữ nhân vật trên mặt phẳng.
- Bài tiếp theo sẽ giải quyết vấn đề tốc độ di chuyển bằng [[Time.deltaTime]].
