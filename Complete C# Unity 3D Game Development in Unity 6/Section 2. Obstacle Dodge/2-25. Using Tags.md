## Kiểm soát va chạm và cập nhật điểm số chỉ một lần với mỗi vật thể

Bài học này hướng dẫn cách dùng tag, điều kiện if và cập nhật điểm số sao cho một vật thể chỉ ghi nhận điểm một lần, cũng như chỉ đổi màu khi va chạm đúng với player.

## 1. Gán tag Player cho đối tượng người chơi

- Chọn GameObject player trong Hierarchy
- Trên Inspector, phần Tag chọn "Player"
- Tag giúp xác định loại đối tượng trong code, hỗ trợ kiểm tra và xử lý điều kiện dễ dàng hơn
- Các vật thể khác giữ trạng thái Untagged, chỉ player mới có tag Player

## 2. Kiểm tra va chạm đúng là do player

Trong script `ObjectHit` (được gắn lên các obstacle hoặc object có thể va chạm):


```csharp
 void OnCollisionEnter(Collision other)
    {
        if (other.gameObject.tag == "Player")
        {
            // Đoạn code đổi màu        
            // Đoạn code đổi tag sang "Hit"    
        }
    }
```

- Sử dụng `other.gameObject.tag` để kiểm tra tag của đối tượng va chạm[[(Unity Tagging)]]
- Dùng phép so sánh == thay vì = (gán giá trị)
- Chỉ khi tag là "Player" thì mới xử lý đổi màu, ngược lại va chạm với đối tượng khác sẽ không làm gì

## 3. Đổi tag sau khi bị va chạm bởi player

- Sau khi đổi màu, gán lại tag của chính object (gameObject.tag) thành "Hit"
- Đầu tiên, thêm tag mới tên "Hit": chọn một obstacle trong Inspector → Tag → Add Tag… → nhấn dấu cộng, nhập Hit (chữ hoa H), nhấn Save
- Trong code:

```csharp
gameObject.tag = "Hit";
```

Sau va chạm với player, obstacle sẽ tự gán tag mình thành "Hit". Điều này dùng để kiểm soát việc mỗi obstacle chỉ bị điểm 1 lần.

## 4. Cập nhật điểm chỉ một lần cho mỗi vật thể

Trong script quản lý điểm (có thể là script `Scorer` gắn vào player):



```csharp
void OnCollisionEnter(Collision other) {     
	if (other.gameObject.tag != "Hit")     
	{         
		// Tăng điểm         
		// Code tăng điểm (ví dụ: score++)     
	} 
}```

- Điều kiện `!= "Hit"` đảm bảo chỉ tăng điểm khi object bị va chạm chưa từng bị đánh dấu là "Hit"
- Sau lần va chạm đầu tiên, obstacle chuyển tag thành "Hit", nên các lần sau không tăng điểm nữa

## 5. Sử dụng if-else linh hoạt với tag

- `==` so sánh bằng (chỉ xử lý khi đúng)
- `!=` so sánh khác (chỉ xử lý khi không đúng)
- Có thể dùng cú pháp sau với `if`:

```csharp
if (other.gameObject.tag != "Hit") 
{     
	// Xử lý va chạm lần đầu 
}
```

- Có thể dùng `return` để thoát sớm nếu không cần xử lý tiếp (advanced, phù hợp khi đã quen code C#)
    

## 6. Kiểm tra hoạt động và hoàn thiện

- Nhấn Play, đối tượng sẽ đổi màu và tăng điểm khi player va chạm lần đầu
- Va chạm tiếp theo không tác động gì, điểm không tăng
- Đối tượng khác khi va chạm với player cũng áp dụng quy tắc này
- Cách này giúp điểm số phản ánh đúng số lượng obstacle mà player đã vượt qua, không phải số lần đâm cùng một obstacle

## 7. Tái sử dụng logic với các object khác nhau

- Vì tag "Hit" và script đều dùng chung logic nên tất cả các obstacle hoặc object sử dụng script này sẽ chỉ ghi nhận một lần cho mỗi va chạm (bởi player)
- Nếu cần nâng cao, có thể mở rộng hệ thống tag cho các nhóm va chạm hoặc loại điểm khác nhau

## Tổng kết ý chính

- Luôn kiểm tra tag object va chạm để xác định đúng đối tượng
- Chỉ đổi màu hoặc tăng điểm nếu là player và object chưa từng bị va chạm trước đó (chưa có tag "Hit")
- Sử dụng tag để ghi nhận trạng thái và tránh cộng điểm nhiều lần cho cùng một object
- Kết hợp tag, if statement và event collision để xây dựng hệ thống gameplay chặt chẽ, hiệu quả, dễ bảo trì
