## Thiết Lập Portrait Camera Trên UI Canvas

## 1. Import GDTv Fleet Characters Package

- Tải về và giải nén gói **Fleet Characters.unitypackage** trong thư mục Resources
    
- Kéo vào `Assets/Gdtv Assets/Fleet Characters` và import toàn bộ
    

## 2. Chuẩn Bị Prefab Nhân Vật và Backdrop

- Trong `Gdtv Assets/Fleet Characters/Character Prefabs`:
    
    - **Commander.prefab** (nhân vật chỉ huy)
        
    - **Navigator.prefab** (nhân vật điều hướng)
        
- Trong `Gdtv Assets/Fleet Characters`:
    
    - **GDTvLocker.prefab** làm backdrop (node light/background)
        

## 3. Tạo Secondary Camera Cho Portrait

1. Trong Scene, tạo empty GameObject `Portraits`
    
2. Child → empty GameObject `LieutenantSnippets`
    
3. Kéo `Navigator.prefab` vào `LieutenantSnippets` → Focus (`F`)
    
4. Child → **Camera** → rename thành `PortraitCamera_Lieutenant`
    
5. Inspector (Camera):
    
    - Remove **Audio Listener**
        
    - Rotation Y = 180°, Position, Field of View điều chỉnh để zoom sát mặt
        
6. Child → kéo `GDTvLocker.prefab` vào dưới `LieutenantSnippets` làm backdrop
    
7. Add **Point Light** dùng để chiếu sáng gương mặt
    

## 4. Tạo Render Texture & UI RawImage

1. Project → tạo `Textures` folder → Create → **Render Texture** → đặt tên `RT_Lieutenant`
    
2. Chọn `PortraitCamera_Lieutenant` → Inspector → gán **Target Texture** = `RT_Lieutenant`
    
3. UI Canvas → **UI → Raw Image** → rename `RawPortrait_Lieutenant`
    
4. Raw Image (RectTransform):
    
    - Anchor / Pivot = Bottom Right
        
    - Width = Height = 450px
        
    - Pos X = −250, Pos Y = 250
        
5. Raw Image → Texture = `RT_Lieutenant`
    

## 5. Tạo Portrait Cho Nhân Vật Thứ Hai

- Tương tự bước 3–4, dùng:
    
    - empty GameObject `GeneralKeir`
        
    - Prefab `Commander.prefab`
        
    - Camera rename `PortraitCamera_Keir`, Render Texture `RT_Keir`
        
    - UI Raw Image rename `RawPortrait_Keir`
        

## 6. Điều Khiển Hiển Thị Qua Timeline

1. Mở **Master Timeline**
    
2. Add Track Group `PortraitWindows`
    
3. Add **Control Track** trong group
    
4. Kéo `Portraits/PortraitCamera_Lieutenant` và `Portraits/PortraitCamera_Keir` vào Control Track
    
5. Đặt các clip control (Active/Inactive) tại các mốc timeline tương ứng với thoại hoặc sự kiện
    

---

**Kết quả**: Hai camera phụ render mặt nhân vật lên UI canvas qua Raw Image, được bật tắt theo Timeline.
