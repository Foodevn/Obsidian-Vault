# Ghi chú học tập: Tạo và triển khai hình ảnh Docker tùy chỉnh

## Tạo và triển khai hình ảnh Docker tùy chỉnh

### Mục tiêu
- Tạo hình ảnh Docker (Docker image) cho một ứng dụng web đơn giản sử dụng khung Python Flask (Python Flask framework).
- Triển khai ứng dụng thủ công để hiểu các bước cần thiết.
- Tạo tệp Dockerfile, xây dựng hình ảnh, và đẩy lên [[Docker Hub]].
- Hiểu cách chạy và truy cập ứng dụng từ hình ảnh Docker.

### Mô tả ứng dụng
- Ứng dụng: Một ứng dụng web đơn giản sử dụng Python Flask, lưu trữ trên GitHub.
- Chức năng:
  - Tuyến đường mặc định (`/`): Hiển thị thông điệp "Welcome".
  - Tuyến đường `/how-are-you`: Trả về thông điệp "I'm good, how about you?".
- Tệp chính: `app.py` chứa mã nguồn ứng dụng.

### Quy trình triển khai thủ công
#### 1. Chuẩn bị môi trường
- Sử dụng hình ảnh cơ sở Ubuntu để tránh cài đặt trực tiếp trên máy chủ Docker.
- Chạy vùng chứa (container) với lệnh:
  ```bash
  docker run -it ubuntu:18.04 bash
  
  docker start -ai 2c8911b9aecd
  docker cp "C:\Users\Administrator\WebstormProjects\docker-webapp-simple\servernodejs" 2c8911b9aecd:/opt
  
  ```
  - `-i`: Gắn đầu vào chuẩn (standard input).
  - `-t`: Gắn thiết bị đầu cuối (terminal).
  - `bash`: Khởi chạy shell để làm việc trong vùng chứa.

#### 2. Các bước cài đặt thủ công
- Cập nhật kho gói:
  ```bash
  apt-get update
  ```
- Cài đặt Python:
  ```bash
  apt-get install -y python
  ```
  - Kết quả: Python 2.7 được cài đặt.
- Cài đặt `pip`:
  ```bash
  apt-get install -y python-pip
  ```
- Cài đặt Flask:
  ```bash
  pip install flask
  ```
- Sao chép mã nguồn:
  - Tạo tệp `app.py` tại `/opt/app.py` trong vùng chứa.
  - cat > /opt/app.py    ctrl+d
  - Nội dung `app.py`:
    ```python
    from flask import Flask
    app = Flask(__name__)

    @app.route('/')
    def welcome():
        return 'Welcome'

    @app.route('/how-are-you')
    def how_are_you():
        return 'I\'m good, how about you?'

    if __name__ == '__main__':
        app.run(host='0.0.0.0', port=5000)
    ```
- Chạy ứng dụng:
  ```bash
  cd /opt
  flask run --host=0.0.0.0
  ```
- Truy cập ứng dụng:
  - Trong vùng chứa, mở trình duyệt tại `172.17.0.2:5000` để xem thông điệp "Welcome".
  - Truy cập `172.17.0.2:5000/how-are-you` để xem thông điệp "I'm good, how about you?".
  - Lưu ý: Cần ánh xạ cổng (port mapping) nếu muốn truy cập từ máy chủ Docker.

### Tạo tệp Dockerfile
#### 1. Ghi lại các bước triển khai
- Dựa trên các bước thủ công, tạo danh sách hướng dẫn:
  - Cập nhật kho gói: `apt-get update`.
  - Cài đặt Python: `apt-get install -y python`.
  - Cài đặt `pip`: `apt-get install -y python-pip`.
  - Cài đặt Flask: `pip install flask`.
  - Sao chép mã nguồn: `app.py` vào `/opt/app.py`.
  - Chạy ứng dụng: `flask run --host=0.0.0.0`.

#### 2. Viết Dockerfile
- Tạo thư mục `my-simple-webapp` và tệp `Dockerfile`:
  ```dockerfile
  FROM ubuntu
  RUN apt-get update && apt-get install -y python python-pip
  RUN pip install flask
  COPY app.py /opt/app.py
  ENTRYPOINT ["python", "/opt/app.py"]
  ```
- **Giải thích**:
  - `FROM ubuntu`: Sử dụng hình ảnh cơ sở Ubuntu.
  - `RUN apt-get ...`: Cập nhật và cài đặt Python, `pip`.
  - `RUN pip install flask`: Cài đặt Flask.
  - `COPY app.py /opt/app.py`: Sao chép tệp `app.py` từ thư mục cục bộ vào `/opt/app.py`.
  - `ENTRYPOINT`: Chạy ứng dụng Flask khi vùng chứa khởi động.

#### 3. Chuẩn bị mã nguồn
- Tạo tệp `app.py` trong cùng thư mục với `Dockerfile`, chứa mã nguồn như trên.

### Xây dựng hình ảnh
- Chạy lệnh xây dựng:
  ```bash
  docker build -t <tên-image>:<tag> <đường-dẫn-Dockerfile>

  docker build -t my-simple-webapp .
  ```
- Kết quả: Hình ảnh được xây dựng với các lớp được lưu vào bộ nhớ cache.
- Gắn thẻ với tài khoản:
  ```bash
  docker build -t <tên_tài_khoản>/my-simple-webapp .
  ```
- Kiểm tra hình ảnh:
  ```bash
  docker images
  ```

### Chạy vùng chứa
- Chạy hình ảnh:
  ```bash
  docker run -p 5000:5000 my-simple-webapp
  ```
  - `-p 5000:5000`: Ánh xạ cổng 5000 của vùng chứa tới cổng 5000 của máy chủ.
- Truy cập ứng dụng từ máy chủ tại `localhost:5000` hoặc `localhost:5000/how-are-you`.

### Đẩy hình ảnh lên Docker Hub
#### 1. Đăng nhập Docker Hub
- Chạy lệnh:
  ```bash
  docker login
  ```
- Nhập tên người dùng và mật khẩu.

#### 2. Đẩy hình ảnh
- Chạy lệnh:
  ```bash
  docker push <tên_tài_khoản>/my-simple-webapp
  ```
- Lưu ý: Hình ảnh phải được gắn thẻ với tên tài khoản (ví dụ: `mmumshad/my-simple-webapp`). Nếu không, Docker sẽ cố đẩy lên kho mặc định (`library`), dẫn đến lỗi từ chối truy cập.

#### 3. Kiểm tra trên Docker Hub
- Truy cập [[Docker Hub]], vào dashboard của tài khoản để xem hình ảnh `my-simple-webapp`.
- Hình ảnh công khai có thể được kéo xuống bởi bất kỳ ai với lệnh:
  ```bash
  docker run -p 5000:5000 <tên_tài_khoản>/my-simple-webapp
  ```
- Lưu ý: Với tài khoản miễn phí, chỉ có thể tạo một kho lưu trữ riêng tư (private repository).

### Ghi chú thêm
- **Tối ưu hóa Dockerfile**:
  - Kết hợp các lệnh `apt-get` để giảm số lớp:
    ```dockerfile
    RUN apt-get update && apt-get install -y python python-pip && rm -rf /var/lib/apt/lists/*
    ```
  - Xóa bộ nhớ cache `apt` để giảm kích thước hình ảnh.
- **Bảo mật**: Đảm bảo đăng nhập vào Docker Hub trước khi đẩy hình ảnh.
- **Thực hành**: Tạo và đẩy hình ảnh cho các ứng dụng khác để làm quen với quy trình.
