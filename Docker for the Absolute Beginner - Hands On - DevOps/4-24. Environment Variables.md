## Ứng dụng Web đơn giản và Cấu hình Biến môi trường trong Docker

### Mục tiêu
- Hiểu cách tạo một ứng dụng web đơn giản bằng Python hiển thị trang web với màu nền.
- Tìm hiểu cách sử dụng biến môi trường (environment variable) để tùy chỉnh màu nền.
- Nắm cách cấu hình và kiểm tra biến môi trường trong container Docker.

### Khái niệm chính
- **Ứng dụng web đơn giản**: Một ứng dụng Python hiển thị trang web với màu nền được cài đặt trong mã nguồn.
- **Biến môi trường (Environment Variable)**: Dùng để lưu trữ các giá trị cấu hình (như màu nền) bên ngoài mã nguồn, giúp dễ dàng thay đổi mà không cần sửa code.
- **Docker**: Công cụ đóng gói ứng dụng thành container, sử dụng biến môi trường để tùy chỉnh hành vi khi chạy.

### Vấn đề và giải pháp
- **Vấn đề**: Màu nền được hard-code (cố định) trong mã nguồn (ví dụ: màu đỏ). Khi muốn thay đổi màu, cần sửa trực tiếp mã nguồn, điều này không linh hoạt.
- **Giải pháp**: Chuyển giá trị màu nền vào một biến môi trường có tên `APP_COLOR`. Ứng dụng sẽ đọc giá trị này để thiết lập màu nền.

### Cách thực hiện
1. **Tách cấu hình ra biến môi trường**:
   - Thay vì hard-code màu nền trong mã nguồn, ứng dụng đọc giá trị từ biến môi trường `APP_COLOR`.
   - Ví dụ: Nếu muốn màu xanh, đặt `APP_COLOR=blue` trước khi chạy ứng dụng.

2. **Chạy ứng dụng trong Docker**:
   - Đóng gói ứng dụng vào một Docker image.
   - Sử dụng lệnh `docker run` với tùy chọn `-e` để truyền biến môi trường vào container:
     ```bash
     docker run -e APP_COLOR=blue <image_name>
     ```
   - Có thể chạy nhiều container với các giá trị `APP_COLOR` khác nhau (ví dụ: `red`, `green`, `blue`) để hiển thị các màu nền khác nhau.

3. **Kiểm tra biến môi trường trong container đang chạy**:
   - Sử dụng lệnh `docker inspect` để xem thông tin cấu hình của container:
     ```bash
     docker inspect <container_id>
     ```
   - Trong phần `Config` của kết quả, tìm danh sách các biến môi trường đã được thiết lập.

### Ghi chú thêm
- Sử dụng biến môi trường giúp mã nguồn linh hoạt và dễ bảo trì hơn.
- Lệnh `docker inspect` hữu ích để kiểm tra cấu hình container, đặc biệt khi cần debug hoặc xác minh các biến môi trường.
