# Ghi chú học tập: Triển khai ứng dụng bỏ phiếu mẫu với Docker

## Tổng quan về ứng dụng bỏ phiếu mẫu

Ứng dụng bỏ phiếu mẫu (*Example Voting App*) là một dự án mã nguồn mở trên GitHub, thuộc kho lưu trữ (*repository*) Docker Samples. Ứng dụng này được sử dụng để minh họa cách triển khai một ứng dụng đa thành phần (*multi-component application*) sử dụng Docker. Trong bài học này, chúng ta sẽ tìm hiểu:

- **Kiến trúc ứng dụng**: Các thành phần và cách chúng tương tác.
- **Mã nguồn**: Cách các thành phần được xây dựng.
- **Triển khai**: Sử dụng lệnh `docker run` để triển khai từng thành phần.

---

## Kiến trúc ứng dụng

Ứng dụng bỏ phiếu mẫu bao gồm 5 thành phần chính, chia thành 3 ứng dụng tự phát triển và 2 dịch vụ sử dụng sẵn:

- **Ứng dụng bỏ phiếu (Voting App)**: Ứng dụng Python, sử dụng khung (*framework*) Flask để hiển thị giao diện người dùng (*UI*) và gửi phiếu bầu (*vote*) đến Redis.
- **Redis**: Hệ thống hàng đợi tin nhắn (*messaging queue*), lưu trữ tạm thời các phiếu bầu.
- **Worker**: Ứng dụng .NET, xử lý phiếu bầu từ Redis và cập nhật vào cơ sở dữ liệu Postgres.
- **Cơ sở dữ liệu Postgres**: Lưu trữ kết quả phiếu bầu.
- **Ứng dụng kết quả (Result App)**: Ứng dụng Node.js, sử dụng khung Express để hiển thị kết quả từ Postgres.

Các thành phần tương tác như sau:
1. Người dùng bỏ phiếu qua Voting App.
2. Phiếu bầu được gửi đến Redis.
3. Worker lấy phiếu bầu từ Redis và cập nhật vào Postgres.
4. Result App truy vấn Postgres để hiển thị kết quả.

---

## Mã nguồn và Dockerfile

### 1. Ứng dụng bỏ phiếu (Voting App)
- **Mã nguồn**: Được viết bằng Python, sử dụng Flask (`app.py`).
  - **Chức năng**:
    - Xử lý yêu cầu GET: Trả về trang `index.html` để người dùng bỏ phiếu.
    - Xử lý yêu cầu POST: Gửi thông tin phiếu bầu đến Redis.
  - Kết nối tới Redis với tên máy chủ (*hostname*) là `redis`.
- **Dockerfile**:
  ```dockerfile
  FROM python:2.7-alpine
  WORKDIR /app
  COPY requirements.txt .
  RUN pip install -r requirements.txt
  COPY . .
  ENTRYPOINT ["python", "app.py"]
  ```
  - Sử dụng hình ảnh (*image*) Python 2.7 Alpine.
  - Sao chép mã nguồn vào thư mục `/app`.
  - Cài đặt các thư viện Python từ `requirements.txt`.
  - Chạy ứng dụng với lệnh `python app.py`.

### 2. Worker
- **Mã nguồn**: Được viết bằng .NET, file chính là `Worker.java`.
  - **Chức năng**:
    - Kết nối tới Redis và Postgres.
    - Vòng lặp (*while loop*) lấy phiếu bầu từ Redis và cập nhật vào Postgres.
- **Dockerfile**:
  ```dockerfile
  FROM microsoft/dotnet:sdk
  WORKDIR /worker
  COPY . .
  CMD ["dotnet", "run"]
  ```
  - Sử dụng hình ảnh Microsoft .NET SDK.
  - Sao chép mã nguồn vào thư mục `/worker`.
  - Chạy ứng dụng với lệnh `dotnet run`.

### 3. Ứng dụng kết quả (Result App)
- **Mã nguồn**: Được viết bằng Node.js, sử dụng Express (`server.js`).
  - **Chức năng**:
    - Kết nối tới Postgres với tên máy chủ `db`.
    - Đọc kết quả từ Postgres và hiển thị trên giao diện.
- **Dockerfile**:
  ```dockerfile
  FROM node:slim
  WORKDIR /app
  COPY package.json .
  RUN npm install
  COPY . .
  CMD ["node", "server.js"]
  ```
  - Sử dụng hình ảnh Node.js Slim.
  - Cài đặt các phụ thuộc (*dependencies*) từ `package.json`.
  - Chạy ứng dụng với lệnh `node server.js`.

### 4. Redis và Postgres
- Sử dụng các hình ảnh có sẵn trên Docker Hub:
  - Redis: `redis`
  - Postgres: `postgres:9.4`

## Triển khai ứng dụng với Docker Run

### 1. Chuẩn bị mã nguồn
- Sao chép (*clone*) kho lưu trữ từ GitHub:
  ```bash
  git clone <URL của kho lưu trữ>
  cd example-voting-app
  ```
- Kiểm tra các thư mục `vote`, `worker`, `result` để đảm bảo mã nguồn và Dockerfile đầy đủ.

### 2. Xây dựng hình ảnh Docker
- **Voting App**:
  ```bash
  cd vote
  docker build -t voting-app .
  ```
  - Tạo hình ảnh với tên `voting-app`.
- **Worker**:
  ```bash
  cd ../worker
  docker build -t worker-app .
  ```
  - Tạo hình ảnh với tên `worker-app`.
- **Result App**:
  ```bash
  cd ../result
  docker build -t result-app .
  ```
  - Tạo hình ảnh với tên `result-app`.

### 3. Triển khai các container
- **Redis**:
  ```bash
  docker run -d --name redis redis
  ```
  - Chạy container Redis ở chế độ nền (*detached mode*).
- **Postgres**:
  ```bash
  docker run -d --name db postgres:9.4
  ```
  - Chạy container Postgres (phiên bản 9.4) ở chế độ nền.
- **Voting App**:
  ```bash
  docker run -d -p 5000:80 --link redis:redis voting-app
  ```
  - Ánh xạ cổng 80 của container sang cổng 5000 trên máy chủ.
  - Liên kết (*link*) container với Redis bằng tùy chọn `--link redis:redis`.
- **Worker**:
  ```bash
  docker run -d --link redis:redis --link db:db worker-app
  ```
  - Liên kết Worker với cả Redis và Postgres.
- **Result App**:
  ```bash
  docker run -d -p 5001:80 --link db:db result-app
  ```
  - Ánh xạ cổng 80 của container sang cổng 5001 trên máy chủ.
  - Liên kết với Postgres bằng tùy chọn `--link db:db`.

### 4. Kiểm tra ứng dụng
- **Voting App**: Truy cập `http://localhost:5000` trên trình duyệt để bỏ phiếu.
  - Nếu gặp lỗi (*Internal Server Error*), kiểm tra kết nối tới Redis (có thể Redis chưa chạy).
- **Result App**: Truy cập `http://localhost:5001` để xem kết quả.
  - Kết quả sẽ cập nhật ngay khi phiếu bầu được xử lý qua Worker và lưu vào Postgres.
- **Lệnh kiểm tra container**:
  ```bash
  docker ps
  ```
  - Hiển thị danh sách các container đang chạy (`redis`, `db`, `voting-app`, `worker-app`, `result-app`).

## Ghi chú thêm
- **Lỗi phổ biến**:
  - **Tên container trùng lặp**: Nếu container đã tồn tại (ví dụ: `redis`), xóa container cũ bằng lệnh:
    ```bash
    docker rm <tên-container>
    ```
  - **Kết nối thất bại**: Đảm bảo các container được liên kết đúng với tên máy chủ (`redis` hoặc `db`).
- **Tối ưu hóa**:
  - Trong các bài học tiếp theo, có thể sử dụng [[Docker Compose]] hoặc [[Docker Swarm]] để triển khai ứng dụng hiệu quả hơn, thay vì lệnh `docker run` thủ công.
- **Liên kết nội bộ**:
  - Xem thêm về [[Docker Networking]] để hiểu cách các container giao tiếp.
  - Tham khảo [[Flask]], [[Express]], [[.NET]] để tìm hiểu chi tiết về các khung phát triển ứng dụng.

---

**Kết luận**: Ứng dụng bỏ phiếu mẫu đã được triển khai thành công bằng lệnh `docker run`, với các container được liên kết để giao tiếp. Quy trình này giúp hiểu cách xây dựng và triển khai ứng dụng đa thành phần với Docker.
