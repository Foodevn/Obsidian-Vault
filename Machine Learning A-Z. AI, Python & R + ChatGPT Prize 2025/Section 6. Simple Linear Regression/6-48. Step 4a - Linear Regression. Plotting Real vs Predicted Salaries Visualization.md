# Trực quan hóa kết quả trên Tập huấn luyện (Visualising the Training Set Results)

## Mục tiêu

Vẽ biểu đồ so sánh giữa dữ liệu thực tế và đường hồi quy (dữ liệu dự đoán) trên **tập huấn luyện**.
- **Trục hoành ($X$)**: Số năm kinh nghiệm `(Years of Experience)`.
- **Trục tung ($Y$)**: Mức lương `(Salary)`.
- **Biểu diễn**:
    - Dữ liệu thực tế: Các điểm chấm màu đỏ (`Red points`).
    - Dữ liệu dự đoán: Đường thẳng màu xanh (`Blue straight line`).

## Các bước thực hiện với Matplotlib

1. **Vẽ các điểm dữ liệu thực tế**  
    Sử dụng hàm `scatter` để vẽ biểu đồ phân tán các điểm dữ liệu thật.
	```python
	plt.scatter(X_train, y_train, color='red')
	```
    - `X_train`: Tọa độ $X$ (năm kinh nghiệm thực tế).
    - `y_train`: Tọa độ $Y$ (lương thực tế).
    - `color='red'`: Màu đỏ để dễ phân biệt
2. **Vẽ đường hồi quy (Dự đoán)**  
    Sử dụng hàm `plot` để vẽ đường thẳng biểu diễn các giá trị dự đoán.
    ```python
    plt.plot(X_train, regressor.predict(X_train), color='blue')
    ```
    - `X_train`: Tọa độ $X$.
    - `regressor.predict(X_train)`: Tọa độ $Y$ (Lương dự đoán trên chính tập huấn luyện).
    - `color='blue'`: Màu xanh cho đường dự đoán.
3. **Thêm thông tin biểu đồ**  
    Làm rõ nghĩa cho biểu đồ bằng tiêu đề và nhãn trục.
    ```python
    plt.title('Salary vs Experience (Training set)') 
    # Tiêu đề plt.xlabel('Years of Experience')               
    # Nhãn trục X plt.ylabel('Salary')                            
    # Nhãn trục Y
    ```
4. **Hiển thị biểu đồ**  
    Lệnh cuối cùng để xuất biểu đồ ra màn hình.
    ```python
    plt.show()
    ```

## Giải thích kết quả

- **Đường màu xanh** là đường hồi quy `(regression line)` tối ưu nhất mà mô hình đã học được.
- Các **điểm màu đỏ** là dữ liệu thực tế. Đường màu xanh càng gần các điểm màu đỏ thì mô hình càng khớp tốt với dữ liệu huấn luyện.

> **Bước tiếp theo**: Áp dụng quy trình tương tự để trực quan hóa kết quả trên **Tập kiểm tra** `(Test set)`.
