## Huấn luyện mô hình Hồi quy tuyến tính đơn (Training the Simple Linear Regression Model)

## Tổng quan quy trình

Sau khi tiền xử lý dữ liệu, bước tiếp theo là xây dựng và huấn luyện mô hình trên **tập huấn luyện** `(training set)`.
- **Thư viện sử dụng**: `Scikit-learn` (tên mã trong code là `sklearn`).
- **Module**: `linear_model`.
- **Lớp**: `LinearRegression`.

## Phân biệt Hồi quy và Phân loại

Trước khi khởi tạo đối tượng, cần nắm rõ sự khác biệt:
- **[[Hồi quy (Regression)]]**: Dự đoán một giá trị thực liên tục `(continuous real value)` (ví dụ: lương, nhiệt độ).
- **[[Phân loại (Classification)]]**: Dự đoán một danh mục hoặc lớp `(category/class)` (sẽ học ở phần sau).

## Các bước triển khai

1. **Import thư viện**: Truy cập module `linear_model` từ `sklearn` để nhập lớp `LinearRegression`.
2. **Khởi tạo đối tượng**: Tạo một biến (thường đặt tên là `regressor`) là một thể hiện `(instance)` hay đối tượng `(object)` của lớp `LinearRegression`.
    - Đối tượng `regressor` này chính là mô hình Hồi quy tuyến tính đơn.
    - Không cần truyền tham số vào `LinearRegression()` vì đây là mô hình cơ bản.
3. **Huấn luyện mô hình**: Sử dụng hàm `fit` để kết nối mô hình với dữ liệu huấn luyện.

## Mã nguồn (Source Code)

```python
# 1. Import lớp LinearRegression từ thư viện Scikit-learn 
from sklearn.linear_model import LinearRegression 
# 2. Khởi tạo mô hình (tạo đối tượng regressor) 
regressor = LinearRegression() 
# 3. Hàm dùng để huấn luyện (kết nối mô hình với tập training) 
# Cú pháp gợi ý: 
regressor.fit(X_train, y_train)
```

> **Ghi chú**: Hàm `fit` là công cụ quan trọng để mô hình "học" từ dữ liệu, tìm ra mối tương quan giữa biến độc lập và biến phụ thuộc.
