## Xử lý Dữ liệu Bị thiếu (Handling Missing Data)

Dữ liệu bị thiếu là vấn đề phổ biến trong các bộ dữ liệu thực tế (ví dụ: ô trống trong file `.csv`). Việc để lại dữ liệu thiếu có thể gây lỗi khi huấn luyện mô hình [[Machine Learning]], do đó cần phải xử lý chúng.
## Các phương pháp xử lý
1. **Xóa bỏ quan sát (Deleting Observation)**:
    - **Cách làm**: Xóa dòng chứa dữ liệu bị thiếu.
    - **Ưu điểm**: Đơn giản.
    - **Nhược điểm**: Có thể làm mất dữ liệu quan trọng.
    - **Khi nào dùng**: Chỉ nên dùng khi tập dữ liệu rất lớn và tỉ lệ dữ liệu thiếu rất nhỏ (khoảng 1%), việc xóa đi không ảnh hưởng đáng kể đến chất lượng mô hình.

2. **Thay thế dữ liệu (Replacing Data)** - _Phương pháp được đề xuất_:    
    - **Cách làm**: Thay thế giá trị bị thiếu bằng một giá trị thống kê của cột đó (trung bình, trung vị, hoặc giá trị xuất hiện nhiều nhất).
    - **Phổ biến nhất**: Thay thế bằng giá trị **trung bình (mean)** của tất cả các giá trị trong cột đó.

## Thực hành: Thay thế bằng giá trị trung bình (Mean Imputation)
Sử dụng thư viện `scikit-learn` (sklearn), một thư viện mạnh mẽ và phổ biến nhất cho Data Science và Machine Learning.
## Công cụ sử dụng
- Lớp: `SimpleImputer`
- Module: `sklearn.impute`

## Mã nguồn (Code)
Đoạn mã dưới đây minh họa cách khởi tạo công cụ để thay thế giá trị thiếu bằng giá trị trung bình.

```python
# Import lớp SimpleImputer từ thư viện scikit-learn 
from sklearn.impute import SimpleImputer 
import numpy as np 
# Tạo một instance (đối tượng) của lớp SimpleImputer 
# missing_values: Chỉ định giá trị cần thay thế (np.nan đại diện cho giá trị rỗng/Not a Number) 
# strategy: Chiến lược thay thế ('mean' là thay thế bằng trung bình) 
imputer = SimpleImputer(missing_values=np.nan, strategy='mean')
```

## Các tham số quan trọng của `SimpleImputer`
- `missing_values`: Giá trị nào trong dữ liệu được coi là "thiếu". Thường dùng `np.nan` (cần import `numpy` as `np`).
- `strategy`: Cách thức tính toán giá trị thay thế.
    - `'mean'`: Giá trị trung bình (phổ biến nhất cho dữ liệu số).
    - `'median'`: Giá trị trung vị.
    - `'most_frequent'`: Giá trị xuất hiện nhiều nhất (thường dùng cho dữ liệu phân loại/category).

---
**Lưu ý**: Bước này mới chỉ là khởi tạo công cụ (`imputer`). Để thực sự thay thế dữ liệu, cần áp dụng `imputer` này vào ma trận đặc trưng (Matrix of Features), sẽ được thực hiện trong bước tiếp theo.
