## Các công cụ Tiền xử lý Dữ liệu (Data Preprocessing Tools)

Đây là các bước kỹ thuật cốt lõi cần thực hiện để chuẩn bị dữ liệu trước khi huấn luyện bất kỳ mô hình Machine Learning nào. Chúng ta sẽ xây dựng bộ công cụ này từ đầu (from scratch) để đưa vào mẫu `Data Preprocessing Template`.

## 1. Nhập thư viện (Import Libraries)

Bước đầu tiên là khai báo các thư viện Python chuẩn luôn được sử dụng trong hầu hết các mô hình học máy.
- Mục đích: Cung cấp các hàm và công cụ để xử lý mảng, tính toán và vẽ biểu đồ.

## 2. Nhập bộ dữ liệu (Importing the Dataset)

Quy trình đưa dữ liệu vào môi trường làm việc:
- Tải dữ liệu lên môi trường (ví dụ: Google Colab).
- Sử dụng code Python để đọc file (thường là định dạng `.csv`).
- **Lưu ý**: Cần phân biệt rõ đâu là biến độc lập (predictors) và đâu là biến phụ thuộc (mục tiêu cần dự đoán).

## 3. Xử lý dữ liệu bị thiếu (Taking care of Missing Data)

Trong thực tế, dữ liệu thường không hoàn hảo và có các ô trống (missing values).
- **Ví dụ trong bài**: Cột lương và tuổi có dữ liệu bị thiếu.
- **Giải pháp**: Học các kỹ thuật tối ưu để điền hoặc xử lý các giá trị này nhằm không làm ảnh hưởng đến quá trình huấn luyện mô hình.

## 4. Mã hóa dữ liệu phân loại (Encoding Categorical Data)

Máy tính chỉ hiểu các con số, do đó cần chuyển đổi dữ liệu dạng chữ (text) sang dạng số.
- **Biến độc lập (Independent Variable)**: Ví dụ cột "Quốc gia" (France, Spain, Germany) cần được mã hóa.
- **Biến phụ thuộc (Dependent Variable)**: Ví dụ cột "Purchased" (Yes/No) cũng cần được chuyển đổi.

## 5. Chia tập dữ liệu (Splitting the dataset)

Đây là bước cực kỳ quan trọng để đánh giá hiệu suất mô hình và tránh hiện tượng **Overfitting** (mô hình học quá kỹ dữ liệu huấn luyện nhưng thất bại với dữ liệu mới).
- **Tập huấn luyện ([[Training Set]])**: Dùng để mô hình học các mối tương quan.
- **Tập kiểm tra ([[Test Set]])**: Dùng làm dữ liệu mới để kiểm tra khả năng dự đoán của mô hình.

## 6. Co giãn đặc trưng (Feature Scaling)

Đưa các đặc trưng về cùng một phạm vi (scale) để đảm bảo tính công bằng khi tính toán.
- **Lưu ý**: Không phải mô hình nào cũng cần bước này, nhưng cần chuẩn bị sẵn trong bộ công cụ để sử dụng khi cần thiết.

## Hướng dẫn thực hành trên Google Colab

Để bắt đầu thực hành viết code từ đầu (thay vì chỉ đọc code mẫu):
1. Mở file Notebook gốc (chế độ Read-only).
2. Chọn `File` -> `Save a copy in Drive` để tạo bản sao có thể chỉnh sửa.
3. **Xóa các ô mã nguồn (Code cells)**: Giữ lại các ô văn bản (Text cells) đóng vai trò tiêu đề/mục lục.
4. Tiến hành viết lại từng dòng code theo hướng dẫn trong các bài học tiếp theo.

> **Lời khuyên**: Khóa học đề cao tính thực hành ("Action-based"). Ngay cả khi bạn đã biết các khái niệm này, việc tự tay viết lại code (re-implement) là cách tốt nhất để nắm vững kiến thức.
