## 1. Nhập Thư Viện Cần Thiết (Importing the Libraries)

Đây là bước đầu tiên trong mọi quy trình xây dựng mô hình học máy. Chúng ta cần import 3 thư viện cốt lõi để xử lý dữ liệu, tính toán và trực quan hóa.

## Các thư viện được sử dụng:
1. **[[NumPy]]**
    - **Mục đích**: Làm việc với mảng (arrays). Các mô hình ML thường yêu cầu đầu vào là mảng.
    - **Cú pháp import**: `import numpy as np`.​
    - **Lưu ý**: `np` là quy ước đặt tên tắt (alias) phổ biến nhất cho NumPy trong cộng đồng Python.[numpy+1](https://numpy.org/doc/stable/user/absolute_beginners.html)​

2. **[[Matplotlib]]** (Module `pyplot`)
    - **Mục đích**: Vẽ biểu đồ và đồ thị trực quan hóa dữ liệu.
    - **Cú pháp import**: `import matplotlib.pyplot as plt`.[coderivers+1](https://coderivers.org/blog/how-to-import-matplotlib-in-python/)​
    - **Chi tiết**: Chúng ta chỉ cần module `pyplot` của thư viện Matplotlib vì nó cung cấp giao diện vẽ đồ thị giống MATLAB rất tiện dụng. `plt` là tên tắt tiêu chuẩn.[numpydoc.readthedocs+2](https://numpydoc.readthedocs.io/en/latest/format.html)​

3. **[[Pandas]]**    
    - **Mục đích**: Nhập bộ dữ liệu (dataset), tạo ma trận đặc trưng (matrix of features) và vector biến phụ thuộc.
    - **Cú pháp import**: `import pandas as pd`.[stratascratch+1](https://www.stratascratch.com/blog/how-to-import-pandas-as-pd-in-python/)​
    - **Lưu ý quan trọng**: Trong video giảng viên dùng `import pandas as pd`. Mặc dù giảng viên có thể lỡ lời nói "pt" ở cuối nhưng cú pháp chuẩn và hiển thị trên màn hình luôn là `pd`. `pd` là quy ước quốc tế giúp tránh xung đột tên với các hàm có sẵn của Python và gõ ngắn gọn hơn.[reddit+1](https://www.reddit.com/r/learnpython/comments/6eovks/what_exactly_does_an_import_statement_like_import/)​

## Mã nguồn (Code Snippet)


``` python
import numpy as np 
import matplotlib.pyplot as plt 
import pandas as pd
```

## Tại sao dùng `as` (Alias)?

- Giúp gọi hàm nhanh hơn (ví dụ: gõ `np.array` thay vì `numpy.array`).[reddit](https://www.reddit.com/r/learnpython/comments/6eovks/what_exactly_does_an_import_statement_like_import/)​
- Tuân theo chuẩn chung của cộng đồng Data Science, giúp code dễ đọc và dễ chia sẻ.[geeksforgeeks+1](https://www.geeksforgeeks.org/numpy/how-to-import-numpy-as-np/)​
- Tránh xung đột tên với các biến hoặc hàm khác trong chương trình.[stackoverflow+1](https://stackoverflow.com/questions/35697404/why-its-a-convention-to-import-pandas-as-pd)​
