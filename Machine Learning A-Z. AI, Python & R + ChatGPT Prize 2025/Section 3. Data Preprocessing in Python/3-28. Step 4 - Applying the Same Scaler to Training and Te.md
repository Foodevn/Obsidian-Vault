## Feature Scaling trên tập kiểm tra (Test Set)

## Quy tắc quan trọng

- Đối với `X_test`, chúng ta **chỉ dùng phương thức `transform`**.
- **Tuyệt đối không dùng `fit` hoặc `fit_transform`**: Vì `X_test` đóng vai trò là dữ liệu mới trong tương lai. Ta phải dùng chính bộ "thước đo" (scaler) đã được huấn luyện trên `X_train` để đo đạc `X_test`. Điều này đảm bảo tính nhất quán (congruent) của mô hình.

## Mã nguồn (Code)

```python
# Chỉ transform các cột số (từ index 3 trở đi) 
# Sử dụng lại đối tượng sc đã fit trước đó 
X_test[:, 3:] = sc.transform(X_test[:, 3:])
```

## Kiểm tra Kết quả Scaling

Sau khi thực hiện, in `X_train` và `X_test` để xác nhận:

1. **Biến giả (Dummy Variables - cột 0, 1, 2)**: Giữ nguyên giá trị 0 và 1 (hoặc xấp xỉ).
2. **Biến số (Age, Salary - cột 3, 4)**: Đã được biến đổi về khoảng giá trị nhỏ (thường từ -3 đến +3 hoặc -2 đến +2).
    - Điều này xác nhận mọi đặc trưng giờ đây đã nằm trên **cùng một thang đo**.

## Mẫu Tiền xử lý Dữ liệu Chuẩn (Data Preprocessing Template)

Để tối ưu hóa quy trình làm việc cho các bài học sau, giảng viên cung cấp một **Template chuẩn**. Template này bao gồm 3 bước bắt buộc phải có cho hầu hết mọi dự án Machine Learning.

## Cấu trúc Template
Template này được thiết kế để bạn chỉ cần thay đổi **đúng 1 chỗ duy nhất** là tên file dataset.
1. **Import thư viện**: Luôn cần numpy, matplotlib, pandas.
2. **Import bộ dữ liệu**:
    - Code được viết tổng quát để tự động lấy tất cả cột trừ cột cuối làm `X` và cột cuối cùng làm `y`.
    - **Điểm cần sửa duy nhất**: Tên file `.csv`.
3. **Chia tập dữ liệu (Splitting)**: Luôn chia thành Train/Test set (thường là tỷ lệ 80/20).

_(Lưu ý: Phần xử lý dữ liệu thiếu, mã hóa, và Feature Scaling không được đưa vào Template mặc định vì không phải mô hình nào cũng cần dùng đến chúng, hoặc cách dùng sẽ khác nhau tùy dữ liệu)._

```python
# Data Preprocessing Tools
# Importing the libraries
import numpy as np
import matplotlib.pyplot as plt
import pandas as pd

# Importing the dataset
dataset = pd.read_csv('Data.csv')
X = dataset.iloc[:, :-1].values
y = dataset.iloc[:, -1].values
print(X)
print(y)

# Taking care of missing data
from sklearn.impute import SimpleImputer
imputer = SimpleImputer(missing_values=np.nan, strategy='mean')
imputer.fit(X[:, 1:3])
X[:, 1:3] = imputer.transform(X[:, 1:3])
print(X)

# Encoding categorical data
# Encoding the Independent Variable
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import OneHotEncoder

ct = ColumnTransformer(transformers=[('encoder', OneHotEncoder(), [0])], remainder='passthrough')
X = np.array(ct.fit_transform(X))
print(X)

# Encoding the Dependent Variable
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
y = le.fit_transform(y)
print(y)

# Splitting the dataset into the Training set and Test set
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size = 0.2, random_state = 1)
print(X_train)
print(X_test)
print(y_train)
print(y_test)

# Feature Scaling
from sklearn.preprocessing import StandardScaler
sc = StandardScaler()
X_train[:, 3:] = sc.fit_transform(X_train[:, 3:])
X_test[:, 3:] = sc.transform(X_test[:, 3:])
print(X_train)
print(X_test)
```
