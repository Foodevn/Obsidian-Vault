## 2. Nhập Bộ Dữ liệu (Importing the Dataset)

Sau khi nhập thư viện, bước tiếp theo là tải dữ liệu từ file CSV vào môi trường Python và chia tách thành các thành phần cần thiết cho Machine Learning.

## 2.1. Đọc file CSV bằng Pandas

Hàm `read_csv` của thư viện **Pandas** được sử dụng để đọc file `.csv` và tạo ra một **Data Frame** (khung dữ liệu).

- **Cú pháp**:
 ```python
dataset = pd.read_csv('Data.csv')
   ```
- **Giải thích**:
    - `pd`: Tên tắt của thư viện Pandas đã khai báo trước đó.
    - `read_csv`: Hàm đọc dữ liệu.
    - `'Data.csv'`: Tên file dữ liệu (lưu ý phải chính xác cả phần mở rộng).
    - `dataset`: Biến chứa Data Frame (toàn bộ bảng dữ liệu gồm hàng và cột).

## 2.2. Nguyên tắc Cơ bản trong Dữ liệu Machine Learning

Hầu hết các bộ dữ liệu dùng để huấn luyện mô hình đều bao gồm hai thành phần chính:
1. **Các đặc trưng (Features / Independent Variables)**:
    - Là các cột chứa thông tin dùng để dự đoán.
    - Thường nằm ở các cột đầu tiên của bộ dữ liệu.
    - _Ví dụ trong bài_: Country (Quốc gia), Age (Tuổi), Salary (Lương).

2. **Biến phụ thuộc (Dependent Variable / Target)**:    
    - Là cột chứa kết quả mà chúng ta muốn dự đoán.
    - Thường nằm ở cột cuối cùng.
    - _Ví dụ trong bài_: Purchased (Đã mua hay chưa - Yes/No).

## 2.3. Tạo Ma trận Đặc trưng (Matrix of Features - X) và Vector Biến phụ thuộc (Dependent Variable Vector - y)

Bước tiếp theo là tách Data Frame `dataset` thành hai biến riêng biệt `X` và `y` để phục vụ cho việc huấn luyện mô hình.
## a. Tạo Ma trận Đặc trưng (X)
Lấy tất cả các hàng và tất cả các cột **ngoại trừ cột cuối cùng**.

```python
X = dataset.iloc[:, :-1].values
```

- `.iloc`: Hàm dùng để định vị và lấy dữ liệu theo chỉ số (index).
- `[:, :-1]`:
    - Dấu `:` đầu tiên: Lấy tất cả các hàng.
    - `:-1`: Lấy tất cả các cột từ đầu đến trước cột cuối cùng (bỏ cột cuối).
- `.values`: Chuyển đổi Data Frame thành mảng NumPy (NumPy Array) để các mô hình Machine Learning có thể xử lý.

## b. Tạo Vector Biến phụ thuộc (y)

Chỉ lấy cột cuối cùng của bộ dữ liệu.



```python
y = dataset.iloc[:, -1].values
```

- `[:, -1]`:
    - Dấu `:` đầu tiên: Lấy tất cả các hàng.
    - `-1`: Chỉ số của cột cuối cùng trong Python.

## Tóm tắt quy trình code


```python
dataset = pd.read_csv('Data.csv') 
X = dataset.iloc[:, :-1].values 
y = dataset.iloc[:, -1].values
```
