## Kiểm tra Kết quả One-Hot Encoding
Sau khi chạy mã One-Hot Encoding cho cột Country, sử dụng lệnh `print(X)` để kiểm tra.
- **Kết quả quan sát**: Cột Country (dạng chữ) biến mất. Thay vào đó là 3 cột mới ở đầu ma trận, chứa các vector nhị phân (0 và 1).
    - **France**: `1.0, 0.0, 0.0`
    - **Spain**: `0.0, 0.0, 1.0` (trong ví dụ cụ thể của bài học, thứ tự vector có thể thay đổi tùy phiên bản thư viện nhưng nguyên tắc là mỗi quốc gia có 1 vector duy nhất).
    - **Germany**: `0.0, 1.0, 0.0`
- **Ý nghĩa**: Không còn thứ tự số học giữa các quốc gia, đảm bảo mô hình máy học hoạt động chính xác nhất.

## Mã hóa Biến Phụ thuộc (Dependent Variable Encoding)
Biến phụ thuộc `y` chứa các giá trị "No" và "Yes". Cần chuyển đổi chúng thành dạng số (0 và 1).
## Công cụ sử dụng
- Lớp: `LabelEncoder`
- Module: `sklearn.preprocessing`
## Quy trình thực hiện

Khác với `ColumnTransformer` (dùng cho nhiều cột phức tạp), `LabelEncoder` đơn giản hơn và thường dùng cho biến mục tiêu đơn lẻ.

1. **Import thư viện**:
```python
from sklearn.preprocessing import LabelEncoder
```

2. **Khởi tạo đối tượng**:  
    Tạo biến `le` từ lớp `LabelEncoder`. Không cần tham số đầu vào.
```python
le = LabelEncoder()
```

3. **Áp dụng biến đổi (Fit & Transform)**:  
    Sử dụng phương thức `fit_transform` trực tiếp lên vector `y`. Không cần ép kiểu sang NumPy array bắt buộc như `X`.
```python
y = le.fit_transform(y)
```

## Kiểm tra kết quả
In biến `y` để xác nhận:
```python
print(y)
```

- **Kết quả**:
    - "No" được chuyển thành `0`.
    - "Yes" được chuyển thành `1`.
- Dữ liệu `y` lúc này là một mảng các số 0 và 1, sẵn sàng cho việc huấn luyện mô hình.
