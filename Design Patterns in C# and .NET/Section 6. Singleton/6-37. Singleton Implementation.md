## Triển khai Singleton trong lập trình

### Giới thiệu
- Phần này hướng dẫn cách xây dựng một **Singleton** cụ thể bằng cách sử dụng một lớp cơ sở dữ liệu (database) làm ví dụ.
- Mục tiêu: Tạo một lớp `SingletonDatabase` đảm bảo chỉ có một thể hiện duy nhất, đọc dữ liệu từ một tệp văn bản (`Capitals.txt`) và cung cấp API để truy vấn thông tin dân số của các thành phố.
- Tập trung vào cách triển khai **lazy initialization** (khởi tạo lười) và đảm bảo **thread safety** (an toàn luồng).

### Giao diện (Interface) cơ sở dữ liệu
- Định nghĩa một giao diện `IDatabase` với một phương thức duy nhất:
  - `getPopulation(city)`: Trả về dân số của một thành phố được cung cấp.
- **Mã nguồn**:
```csharp
public interface IDatabase
{
    int GetPopulation(string city);
}
```

### Triển khai lớp SingletonDatabase
- Lớp `SingletonDatabase` triển khai giao diện `IDatabase`.
- Đọc dữ liệu từ tệp `Capitals.txt` chứa danh sách các thành phố và dân số.
- Sử dụng một từ điển (dictionary) để lưu trữ dữ liệu: từ tên thành phố (string) đến dân số (int).

#### Cấu trúc lớp
- **Biến**:
  - `private static SingletonDatabase instance`: Lưu trữ thể hiện duy nhất của lớp.
  - `private Dictionary<string, int> capitals`: Lưu trữ cặp thành phố-dân số.
- **Hàm tạo (Constructor)**:
  - Được đặt là `private` để ngăn việc tạo thể hiện từ bên ngoài.
  - Đọc tệp `Capitals.txt` và khởi tạo từ điển `capitals`.
- **Phương thức tĩnh**:
  - `public static SingletonDatabase Instance`: Trả về thể hiện duy nhất của lớp.

#### Mã nguồn triển khai
```csharp
public class SingletonDatabase : IDatabase
{
    private static SingletonDatabase instance = null;
    private Dictionary<string, int> capitals;

    // Hàm tạo private để ngăn tạo thể hiện từ bên ngoài
    private SingletonDatabase()
    {
        Console.WriteLine("Khởi tạo cơ sở dữ liệu...");
        capitals = File.ReadAllLines("Capitals.txt")
                      .Batch(2) // Nhóm các dòng thành cặp (tên thành phố, dân số)
                      .ToDictionary(
                          list => list.ElementAt(0).Trim(), // Tên thành phố
                          list => int.Parse(list.ElementAt(1)) // Dân số
                      );
    }

    // Thuộc tính tĩnh để truy cập thể hiện duy nhất
    public static SingletonDatabase Instance
    {
        get
        {
            if (instance == null)
            {
                instance = new SingletonDatabase();
            }
            return instance;
        }
    }

    // Triển khai phương thức từ IDatabase
    public int GetPopulation(string city)
    {
        return capitals[city];
    }
}
```

#### Tệp Capitals.txt
- Định dạng: Mỗi cặp dòng bao gồm tên thành phố và dân số.
- Ví dụ nội dung tệp:
```
Tokyo
33000000
London
8900000
```
- **Cấu hình tệp**: Đặt thuộc tính "Copy if newer" trong Visual Studio để đảm bảo tệp được sao chép vào thư mục đầu ra (output directory).

### Cải tiến: Khởi tạo lười (Lazy Initialization)
- Vấn đề: Khởi tạo `SingletonDatabase` ngay khi chương trình chạy có thể tốn tài nguyên, đặc biệt nếu dữ liệu không được sử dụng.
- Giải pháp: Sử dụng lớp `Lazy<T>` trong C# để trì hoãn việc khởi tạo cho đến khi thể hiện được truy cập lần đầu.

#### Mã nguồn với Lazy Initialization
```csharp
public class SingletonDatabase : IDatabase
{
    private static readonly Lazy<SingletonDatabase> instance = 
        new Lazy<SingletonDatabase>(() => new SingletonDatabase());
    private Dictionary<string, int> capitals;

    private SingletonDatabase()
    {
        Console.WriteLine("Khởi tạo cơ sở dữ liệu...");
        capitals = File.ReadAllLines("Capitals.txt")
                      .Batch(2)
                      .ToDictionary(
                          list => list.ElementAt(0).Trim(),
                          list => int.Parse(list.ElementAt(1))
                      );
    }

    public static SingletonDatabase Instance => instance.Value;

    public int GetPopulation(string city)
    {
        return capitals[city];
    }
}
```
- **Giải thích**:
  - `Lazy<SingletonDatabase>`: Đảm bảo thể hiện chỉ được tạo khi thuộc tính `Instance` được truy cập.
  - `instance.Value`: Kích hoạt hàm tạo khi được gọi lần đầu.
  - **Thread-safe**: `Lazy<T>` tự động xử lý an toàn luồng.

### Sử dụng SingletonDatabase
- Ví dụ truy vấn dân số:
```csharp
class Program
{
    static void Main(string[] args)
    {
        var db = SingletonDatabase.Instance;
        string city = "Tokyo";
        Console.WriteLine($"{city} có dân số {db.GetPopulation(city)}");
    }
}
```
- **Kết quả đầu ra**:
```
Khởi tạo cơ sở dữ liệu...
Tokyo có dân số 33000000
```

### Ưu điểm của triển khai
- **Duy nhất**: Chỉ có một thể hiện của `SingletonDatabase`, tránh lãng phí tài nguyên khi đọc tệp nhiều lần.
- **Khởi tạo lười**: Trì hoãn việc đọc tệp cho đến khi cần thiết.
- **An toàn luồng**: Sử dụng `Lazy<T>` đảm bảo không có điều kiện chạy đua (race condition).

### Hạn chế và câu hỏi mở
- Mặc dù triển khai này hoạt động tốt, Singleton vẫn có những vấn đề tiềm ẩn:
  - Khó kiểm thử (testability) do thể hiện toàn cục (global state).
  - Khó mở rộng (extensibility) khi cần thay đổi hành vi.
- Những hạn chế này sẽ được thảo luận chi tiết trong [[Vấn đề của Singleton]].
